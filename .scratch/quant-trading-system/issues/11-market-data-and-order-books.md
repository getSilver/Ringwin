# 确定订单簿及行情健康模型

Type: grilling
Status: resolved
Blocked by: 02, 06
Parent: [设计生产级多策略低延迟加密量化交易系统](../map.md)

## Question

统一行情模型以什么订单簿为权威，发生重复、乱序、断档或陈旧时如何处理？

## Answer

- 以交易所提供的 L2 价位级订单簿作为统一权威盘口。
- 网关实现各交易所规定的 Snapshot + Delta 同步流程，并检查来源序号、重复、乱序和缺口。
- 订单簿具有 Syncing、Live、Stale、Gap 和 Recovering 状态。
- 只有 Live 状态可向要求实时盘口的策略提供可交易视图。
- 发现 Gap 后停止依赖该盘口的新开仓，重新获取快照并衔接增量。
- BBO、中间价和深度指标从 L2 推导，不形成第二套权威行情状态。
- 成交、指数价格、标记价格和资金费率作为独立行情事实保存；只有 L1 的交易所必须明确降级。
