## Destination

通过逐项设计访谈，形成适用于 Ringwin 的跨所套利策略规格，覆盖经济口径、准入、执行、恢复和验收。

## Definition of done

- 交易范围、资金与数量、费用、资产身份、执行失败、库存和恢复均有明确规则。
- 每项规则有正常及异常场景的可检查结果。
- 用户确认共同理解后，才能进入实现规划。

## Rules

- 当前授权为讨论和文档记录，不包含策略实现或交易。
- 使用根级 GLOSSARY.md 和相关 ADR 的规范领域语言。
- 用户已确认的约束与建议、待决问题分开记录。
- 一次讨论一个关键决策；策略实现任务拆分待规格收敛后进行。用户已要求将三项项目接口能力形成交接规格，交由其他会话处理。
- 交易所选择属于部署配置，不作为策略访谈问题。具体账户、币种名单和资金数值由运行配置提供；策略规格定义输入语义、约束及校验，不要求先选择部署实例。

## Decisions so far

- S5：同次信号内允许未成功预留且未发单时有界重评，每次重查完整门槛，固定期限不延期。结果未知先查证，成功预留即消费信号；到期/次数耗尽或信号资格失效后重新重置及触发。[S5合同](signal-monitoring.md)补齐迟滞、冷却、监测窗口、预警/失效转换和恢复原因隔离。

- S3：采用实际计划收益与目标触发概率保守下界双门槛，在开仓前、入场/修复结束进入Holding前检查。不合格则不入场或按既有规则退出；Holding中不因单次概率下降新增退出规则。触发成功与实际收益达标分开记录；数值及误差证据待校准。

- S2：Pi_reference 只用于一次生成固定止盈目标；真正执行该目标的 Pi_plan 用于准入、数量/模式选择及资金排序。Pi_plan 不回灌调低目标；未过门槛即淘汰候选。两种评估分别校准，不把参考收益当成实际策略收益。

- S1：部分成交后的持仓净目标为 `max(TP_abs_min, q_matched/q_entry_target * TP_entry)`；保留绝对下限，费用/修复亏损计入整个周期收益，不再降低目标。进入 Holding 前只冻结一次，原计划和剩余期限内不可达则退出。算例及待运行向量见合同第8节和附录 V10–V13。

- 成交数量不固定，应随可投入资金变化；具体资金口径和数量算法待定。
- 费用支持配置，不同交易所可能使用不同规则；具体费率可后续填入。
- 币种不固定为 BTC；候选资产选择与准入方式待定。
- 首版交易包含现货与永续、永续与永续及回归持仓逻辑；现货与现货仅保留扫描观察，不授予交易资格。各组合方向见 Q5。
- 允许独立回归交易：当前可执行净价差不为正时，也可按预测收敛后的完整开平仓净收益评估入场；须计入持仓成本及风险缓冲，并单独设置风险预算、最大持仓时间和止损规则。具体阈值待定。
- 候选币种可配置，但每组两腿必须对应同一基础资产；首版不包含不同基础资产之间的统计配对。合约乘数、数量精度和敞口换算仍须校验。
- 首版现货以 USDT 报价，永续采用 USDT 报价及结算的逐仓线性合约，沿用 IsolatedLinearUsdtV1 领域模型；不包含币本位反向合约、跨报价币配对、全仓或组合保证金。各所保证金分别约束。
- 首版不借币卖空现货。现货与永续仅买入现货、做空永续建仓，反向操作用于退出已有配对；永续与永续允许两个方向。使用预置现货做反向库存替换不纳入本轮已批准范围。
- 采用分配给 VirtualPortfolio 的独立策略预算；已结算且入账的盈利可在额度上限内复用，亏损缩减预算。浮盈不自动扩大开仓预算，浮亏仍约束风险；其他账户资金或充值须显式分配。下单同时受已有占用、预留、缓冲和各所实际资金约束。
- 多币种共享剩余策略预算并动态分配，设置单次配对、单基础资产、单 Venue 和策略总占用上限；排序考虑完整成本后预期收益、资金占用、持仓时间与风险。仅分配剩余额度，不因新机会排名更高自动提前平掉已有配对；核心预留防止重复占用，各所实际资金仍分别约束。
- 同一交易配对同时只允许一个活动交易周期，不自动加仓；周期覆盖预留、执行、持仓、退出及对账，结束并满足重新触发条件后才可再次开仓。首次目标内的执行和修复另受执行规则约束。
- 费用采用有适用范围和有效期的配置，覆盖两腿开平仓；不能确认 maker 时按 taker 预算，实际费用按权威事实入账。配置缺失、过期或实际偏差超限暂停相关市场新开仓，保留撤单和风险退出能力；资金费独立估算与入账，费率值可后填但启用前必须完整。
- 新增仓位准入不依赖未结算资金费收入；逐腿估计支出并加入不利变化缓冲，不以预期收入抵消另一腿支出。实际收付正常入账，并检查正常持仓成本和最大持仓期限下的不利资金费预算。
- 入场前固定退出计划版本，持仓期间不自动延长期限或放宽亏损预算，允许按规则收紧风险或提前退出。安全处置优先于模型失效或到期退出，后者优先于正常获利退出；触发不等于成交完成，Unknown 和 Venue 故障另按安全流程处理。
- 首版规格包含 Taker–Taker 与 Maker–Taker 两种执行模式，分别验收；先完成双 IOC 执行闭环，再依据实际费率、成交概率及对冲偏差验收 Maker–Taker。信号、预算和退出约束可复用，执行状态机及启用资格分别定义。
- Maker–Taker 每次确认唯一新增成交后及时按净敞口增量对冲，计入未完成对冲单以防重复；不足最小下单量的尾差有界累计。超限或对冲受阻时停止新增 maker 暴露并撤单，Unknown 先对账，不能当作未成交重发。
- Unknown 时保留原订单身份、预留及可能成交范围，暂停受影响配对和共享相关账户风险资源的新增风险，按原身份对账并尽力撤销相关挂单；不换身份重发或自动另开第三腿。仅执行符合现有权限且在可能成交情形下可证明安全的减险动作，超时告警升级，不以超时扩大权限。
- 已知部分成交不平衡时，在原目标及预设次数、时限、价格、损失预算内有限补齐；不满足条件或预算耗尽则尝试减掉多余部分。修复仍须通过权限及保证金校验，不扩大目标或重置时钟；已匹配部分仅在持仓条件满足时保留，出现 Unknown 转入对账流程。
- 杠杆上限按配置限制并验证实际设置，策略不自动提高杠杆或追加逐仓保证金。开仓前留安全缓冲，资金不足缩量或跳过；持仓触及安全门槛按风险等级停止新增风险并受控退出，各所保证金分别满足约束。
- 扫描器可自动发现和统计机会，交易仅在显式启用的配对白名单内进行；白名单绑定资产、两腿 Venue/账户/Instrument 和合格执行模式，新增配对验证后启用。运行时仍持续准入，禁用不抹除存量仓位和管理责任。

- 模型及参数离线进行时间顺序样本外验证，版本化显式启用；在线按既定规则更新指标和监测失效，不自动搜索替换交易参数。决策绑定模型版本与数据边界，存量周期继续遵守固定退出计划。

- 回归模型采用滚动统计与 AR(1) 基线、动态中心加回归偏离的状态空间挑战模型并行验证；统一时间切分、成本、执行模拟与风险约束，以样本外净收益、回撤、超时退出及预测校准证据选择活动模型，不自动启用或混合投票。

- 回归交易研究以分钟至小时级为主，预先登记 5、15、60 分钟预测评估候选；验证后按配对选择活动期限，硬性最长持仓另定。执行与对冲仍遵守短时安全约束。

- 模型采用固定时间网格，首轮研究以 1 秒采样为基线；执行与风控消费最新有效盘口。只使用当时已接收且准入的数据，校验两腿新鲜度、连续性及时间差；缺口不插值、不回填历史决策，恢复须重新取得资格。

- 目标数量在已分配预算内比较合法候选，检查完整成本后净收益金额及收益率、深度、保证金、集中度和单腿失败风险，选择合格候选中保守预期净收益金额最高者；全部不合格则跳过。Maker–Taker 纳入成交概率和条件对冲成本，执行开始后不扩大原目标。

- 策略整体设置日损失和净值回撤限额，计入浮亏及完整成本并调整外部资金流；触线后锁存新增风险权限、撤销入场挂单并受控退出。跨日、重启或净值反弹不自动解锁，完成对账及复核并满足安全准入后显式恢复。

- 重启先恢复原周期及核心权威状态并完成 Venue 对账，停机时间计入持仓期限，风险锁存和预算不重置；核实并撤销遗留入场挂单，处理迟到成交。自动安全处置须符合恢复权限，新开仓在全部门槛通过后由用户显式恢复。

- 首版策略不自动跨所提现或划转；单所资金不足时缩量或跳过，报告资金缺口。实际调度单独授权，在途资金不算购买力，到账、对账且明确策略归属后方可使用。

- 扫描器比较开仓模式及 maker 腿并提供初始建议；策略可在已授权、已验收集合内自动采用执行前重新校验后的建议，人工限定允许范围及风险上限。周期开始执行后固定开仓模式，maker 超时撤单核实并处理敞口，不在撤单未确认时切换追单。

- 两种开仓模式均采用带价格保护的限价 IOC 退出，按实际剩余持仓及未完成订单计算数量；正常止盈检查可执行净收益，风险或到期退出不要求盈利。进入退出后不重新开回已平仓位，不无限追价，无法成交告警升级，Unknown 按既定规则处理。

- 无合法单独清理方式的现货尾差，可在订单及经济对账闭合、无 Unknown 且单笔/累计/时限均合格时登记为同组合残余库存，周期标记完成但含残余；真实数量和成本继续计入净值及风险。永续残仓不豁免，未清除前周期未完成。

- 采用样本外研究、事件级回放及故障测试、只读影子运行、另行授权的受限真实验证路线；正确性与经济有效性分开，两种执行模式独立取得资格，Demo/Testnet 不替代真实收益证据。当前不启动测试或交易。

- Maker 报价受对冲深度、完整成本、回归目标及风险缓冲约束，持续检查并预留对冲能力；首版撤旧确认成交后再挂新，同一 maker 腿最多一张活跃入场挂单。改价有频率、次数及总寿命限制，换单不重置周期，安全撤单不等待普通间隔。

- 首版本策略以 ExchangeAccount + Instrument 独占活动配对占用，两腿共同准入；退出和对账闭合后释放，Unknown 或永续残仓不释放。运行资格要求相关账户品种范围无其他策略或人工并发写入，外部变化仍通过对账检测。

- 正常完成或完全未成交撤单后，须对账闭合、冷却并在有效数据上观察信号重置及再次触发才可新开周期；止损、模型失效、对账异常或修复失败须复核并显式恢复，不能对同一持续异常反复开仓。

- 分别记录交易边际收益率（保守预期净收益/单边参考名义金额）与资金效率（同一净收益/计划占用资金）。前者用于入场门槛，后者结合时间和风险分配预算；预留去重，预测风险缓冲与实际账本费用分开。

- 多机会先通过硬约束，再按保守预期净收益/(计划占用资金×保守预计占用时间)排序；占用时间含挂单等待、持仓、退出及对账并设下限。逐次预留后重算剩余候选，确定性打破并列，不宣称组合全局最优。

- 回归收益仅认可活动预测期限内、经样本外校准和不确定性折减后的预计有利变化，不默认完全回到历史均值；扣除完整成本后准入，入场绑定目标及校准版本，正常退出仍依据实际可执行净收益。

- 模型健康分正常、预警和失效；预警暂停相关新增周期并撤销入场挂单，健康持仓继续原退出计划，连续健康后可按规则解除；失效锁存并受控退出，复核后显式恢复。统计证据须满足有效样本量及持续性，独立行情和风险硬门槛优先。

- 正常止盈采用入场固定的净收益目标，可为保守预测收益的经验证比例；尽量盈利最大化指风险约束内优化样本外完整净收益，不授权达到目标后延期或追踪止盈。公式、状态和验收矩阵见策略合同草案。
