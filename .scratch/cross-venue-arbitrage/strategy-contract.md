# 跨所价差回归策略合同草案

更新日期：2026-10-20。

本文件是[规格访谈](issues/01-strategy-spec.md)的整理稿。已确认的行为保持不变；为使其可复算而补充的公式、状态名和参数校准方法是设计草案，不代表已实现、已验证盈利或已取得交易资格。部署名单不属于策略决策。

算法细化见[模型、成本、校准与接口验证附录](algorithm-validation.md)：包含预测递推、联合经济场景、执行成本、数量网格、校准隔离、可复算向量及当前核心接口差距。附录不改变本合同已确认的行为。

项目接口改造交由其他会话按[交接规格](issues/02-core-interface-handoff.md)处理；本会话的[策略细化工作面](strategy-refinement.md)单独记录待决行为，未确认提案不覆盖本合同。

## 1. 目标与边界

在资金、敞口、保证金、亏损和时间约束内，提高完整成本后的样本外策略净收益。不能以提高杠杆、自动加仓、放宽止损、延长期限或忽略失败交易实现表面收益最大化。

支持同基础资产的现货多头/USDT 线性永续空头，以及跨所 USDT 线性永续多空配对。永续逐仓，不借币卖空现货。现货与现货仅扫描观察。具体 Venue、账户、币种和资金由运行配置提供。

每个配对只有一个活动周期；本策略内同 ExchangeAccount + Instrument 只能归一个活动配对占用。首版相关账户品种范围不与其他策略或人工同时交易，外部变化仍需对账检测。独占不意味着不同币种可重复使用同一账户资金。

策略通过 OrderIntent/IntentGroup 请求动作；核心负责交易权限、风险、预留、命令及权威账本。IntentGroup 不保证跨所原子成交，现有 PartialExecutionPolicy 也不等同于本策略的补齐机制。Venue 私有事件只在 VenueAdapter 中转换，公共行情由 MarketFeedAdapter 提供。

## 2. 输入与可见时间

输入包括规范盘口与健康事实、InstrumentRules、费用配置、资金费率及结算日程、账户和组合状态、风险门槛、模型版本及策略授权。

模型先以 1 秒固定网格研究 5/15/60 分钟预测期限。执行与风控按最新有效事实响应，不等待模型采样。网格只引用截止时已接收并准入的信息；校验双腿新鲜度、连续性和时间差。缺口不插值，不删除缺口后将远隔样本当作连续 1 秒样本；迟到数据不重写旧决策。

行情健康恢复后，按模型版本的缺口处理及预热规则重新取得资格；健康恢复不解除停机锁存。实时 Kalman filtering 可用，含未来信息的 smoothing 不可用于历史决策模拟。

## 3. 预测与经济评估

固定两腿顺序，统计输入为 S(t)=ln(mid_B/mid_A)。报价和数量先转换到规范资产单位。Z-score 只表示偏离，不代表必然回归，也不替代经济准入。

滚动统计/AR(1) 为基线，动态中心加回归偏离的状态空间模型为挑战模型。按时间切分训练、验证及保留测试；选择目标、窗口和阈值只能使用训练及验证阶段。所有候选不合格则只观察。模型离线验证并显式启用，在线按版本既定规则更新状态，不自动重新搜索交易参数。

对每个模式 m 和规范数量 q，用户已确认按以下顺序评估：

    Pi_reference(m,q) = E[Y_reference | 当前可见信息, m,q] - B_reference
    TP_entry = max(TP_abs_min, alpha * Pi_reference)
    Pi_plan(m,q) = E[PnL_full_cycle(TP_entry) | 当前可见信息, m,q] - B_model - B_execution

Pi_reference 是目标生成参考收益，仅用于一次确定 TP_entry；参考退出政策版本化，受原风险与期限约束，不以尚未确定的止盈目标为输入。随后模拟真正执行固定止盈的完整交易，得到 Pi_plan。准入、数量、模式及资金排序一律使用 Pi_plan；不得使用较高的参考收益替代，也不得把 Pi_plan 回灌重算目标以通过准入。旧文档的 Pi_cons 在准入与排序语境中仅指 Pi_plan，不再兼任目标生成依据。

参考与实际计划使用同一可见信息和联合场景口径，分别执行退出政策并校准各自误差；成本或缓冲不得重复扣减。参考非正或证据不合格时不能由正的绝对止盈下限产生合格候选。目标可达性采用第 8 节已确认的独立概率门槛；Pi_plan 低于目标金额本身不等于目标不可达。

PnL_full_cycle 包含成交、未成交、部分成交后修复或退出等结果，以及完整开平仓费、资金费支出和适用的清理成本。Maker 必须估计成交条件下的对冲结果，不能把全量成功利润简单乘一个独立成交概率，并忽略失败损失。未来资金费收入在准入中按零计，逐腿支出不被预计收入抵消；实际资金费收付正常入账。

收益只计活动期限内保守可实现的价差变化，不默认回到长期中心。缓冲必须说明覆盖风险，已计入分布或成本的同一损失不能重复扣除。缺少合格成本或校准证据时该模式不参与交易排序。

## 4. 数量、费用和收益率

用基础资产经济敞口匹配两腿，不分别按相同 USDT 金额或相同合约张数下单。候选 q 受步长、最小数量、名义金额、合约乘数和扣费资产约束。规范化后重新计算净敞口、费用、收益和保证金。

    N_ref = q_matched * P_ref
    Edge_bp = 10000 * Pi_plan / N_ref
    Capital_efficiency = Pi_plan / Capital_reserved

P_ref 是明确来源和时点的共同参考价格，仅用于名义金额与风险比较，不能替代实际买卖盘口计算利润。Capital_reserved 含现货买入支出、内部保证金、费用及修复预留；重叠缓冲去重，保证金预留不是账本费用。

账户/产品费用规则允许 Instrument 覆盖，记录版本、扣费 Asset 和有效期。预估按可能的实际执行类型计费，无法确认 maker 则按 taker 预算。实际费用由权威事实入账。缺失、过期或偏差超限停相关新增风险，但不阻断获准的安全撤单和退出。

算例（仅验证口径）：现货买入 10 个资产、成交价 100 USDT，手续费以基础币扣除 0.01 个，则现货净增 9.99 个。若永续每张对应 0.01 个，匹配目标为 999 张而非 1000 张；仍须检查实际规则是否允许。0.01 个手续费按费用估值入账，不能再把它当成另一次凭空丢失。

## 5. 资金和候选选择

预算来自 VirtualPortfolio 的明确分配，已结算入账盈利在上限内复用，亏损缩减预算，浮盈不自动扩大购买力。资金归属、组合可用额度和每所实际可用余额分别检查，同一占用不重复扣除。其他账户资金、在途转账和另一所浮盈不能视为即时购买力。

在有界合法数量网格中，每个配对/模式先选择通过全部硬约束且 Pi_plan 最大的 q；并列选占用较小者。金额和 Edge_bp 均须超过门槛，单腿失败情形也须可承受。无合法候选则跳过，不强求用满本金。

在确定批次的可见状态上，对候选计划排序：

    Score = Pi_plan / (Capital_reserved * max(T_occupancy, T_floor))

T_occupancy 包含实际固定止盈计划下等待、持仓、退出、对账的保守预计占用时长。并列依次比较较高 Pi_plan、较低占用，再按稳定身份排序。核心成功预留一个计划后重算其他候选，互斥模式和共享品种不能重复选中。此为可复算启发式，不保证全局最优。

数量网格、批次窗口和估计时长都须版本化、验证；不能以线程到达先后代替确定顺序。部署前风险额度必须填写并校验，但形成通用规格不要求指定具体本金。

## 6. 执行与模式选择

扫描器比较 Taker–Taker、A maker/B taker、B maker/A taker，输出模式、角色、数量、收益、风险、证据版本和有效期。策略可在已授权且独立合格的模式集合内自动采用建议；发单前复核，周期执行开始后固定开仓模式。

Taker–Taker 在整组准入和预留后尽量并发发送有价格保护的限价 IOC；不等待第一腿成交。第一腿已发而第二腿失去资格时，进入部分执行处置，不将整组视为未发生。

Maker–Taker 挂价受完整周期收益和对冲条件约束。保留剩余挂单可能全成交所需的资金和修复能力；资金预留不能保证未来深度仍在。按唯一已应用 Fill 及时重算对冲，不主动等整单成交。已发送对冲的可能成交量必须纳入计算。

首版每个 maker 腿最多一张活跃入场挂单；撤旧终态及成交核对完成后才替换。换单不重置目标和周期时钟。安全撤单不等待普通改价间隔。剩余量、挂价、改价次数及总寿命受固定计划约束。

## 7. 部分成交和 Unknown

已知残余敞口可在原目标、权限、价格、时限、次数和损失预算内有限补齐；否则尝试减少多余成交。不得追逐尚未发生的目标余量。补齐可能增加单腿仓位，不等于 Reduce-only。

例如 A 买 1 ETH、B 卖 0.6 ETH，原单均终结：合格时 B 补卖 0.4；否则尝试 A 卖回 0.4。匹配的 0.6 仅在持仓准入仍成立时保留，否则受控退出。

未知订单以区间表达可能敞口。A 已买 1，B 可能卖 0～1，则残余为 [0,1]，不能直接再卖 1。保留订单身份及预留，按原身份查证，单次未找到不是未成交证明。不换身份重发、不自动开第三腿。

暂停受影响配对及共享风险资源的新增风险，尽力撤销遗留 maker 挂单。只有满足权限且在可能成交情形下可证明安全的减险动作可自动执行；不能证明时持续查询并升级告警。超时不扩张权限，风险继续显式存在。

## 8. 固定止盈与盈利优化

用户确认：入场固定净收益止盈目标，尽量盈利最大化。

已确认的目标生成顺序：

    TP_cycle = TP_entry = max(TP_abs_min, alpha * Pi_reference)
    0 < alpha <= 1

alpha 和 TP_abs_min 在训练/验证阶段选择，绑定模型与风险配置版本。若目标不具备合理可达性，则候选不入场；不能利用更高止盈目标把差机会包装成高收益机会。

当最新有效盘口下预计立即退出的完整周期净收益 P_exit(t) >= TP_cycle，触发正常退出。入场 Pi_reference 及生成的目标固定；Pi_plan 不反向修改目标，当前成本变化也不用于临时上调目标。仅浮盈转正而未达目标，不触发正常止盈。风险、模型失效和到期优先。

两腿匹配但部分成交时，用户已确认按实际匹配比例缩放净止盈目标，保留入场配置的绝对下限，不因修复亏损再降低目标。记入场原净目标为 TP_entry（即上述入场 TP_cycle），原匹配目标数量为 q_entry_target：

    r = q_matched / q_entry_target, 0 < r <= 1
    TP_holding = max(TP_abs_min, r * TP_entry)

在入场及有限修复结束、订单成交核实且无 Unknown 后，进入 Holding 前只确定一次 TP_holding，之后将其作为本周期正常止盈比较目标，不再按退出中的剩余数量缩放。q_matched=0 不进入 Holding。模型、alpha、原价格目标及最晚期限均不重新拟合或起算；持仓资格或目标可达性验证失败则受控退出。

整个周期的 P_exit 包含此前实际费用、资金费及修复净损失。将已完成部分的实际净损益记为 R_done，将剩余头寸从账本成本到退出的净贡献记为 U_exit，两部分成本不重叠，则 `P_exit=R_done+U_exit`，剩余所需净贡献为 `TP_holding-R_done`。已付成本影响可达性和实际净收益，不作为降低 TP_holding 的减项。

算例：原目标8、匹配一半、绝对下限2，持仓目标为4；若此前修复净亏1，剩余净贡献至少5才能使整个周期达到4。某条路径剩余净贡献4.5时，周期净收益3.5不能触发目标4；若4.5只是跨路径均值，不能据此直接判定目标不可达。应按下述概率门槛判断持仓资格，未通过则受控退出，不降低目标或延长期限。仅匹配10%时目标仍为2而非0.8。

用户已确认 S3 双门槛：开仓前，实际计划收益与既有风险准入必须合格，同时在原风险边界及剩余机会窗口内合法触发固定止盈的概率保守下界须达到门槛。入场/有限修复结束、进入 Holding 前，按真实匹配量、实际成本及剩余期限重新检查持仓资格与该阶段概率门槛；不机械复用原目标数量对应的开仓净收益金额门槛。概率通过不能豁免经济或风险不合格。

    probability_gate(stage) = evidence_qualified(stage)
                              AND p_lower(stage) >= p_min(stage)

开仓前 p_entry 的分母包含全部计划场景，不删除零成交、拒绝或失败；持仓前 p_hold 条件于已核对成交状态，不再次乘入场成交概率。p_entry_min 与 p_hold_min 分别预登记、校准和版本化，无合格证据时不能默认通过。估计方法及验收向量见[已确认 S3](strategy-refinement.md#s3-已确认收益与目标触发概率双门槛)，具体数值尚待校准。

触发事件要求有效可执行盘口下 P_exit 达到该路径固定目标，且硬风险、模型失效或到期退出未先发生；同刻按原优先级处理。窗口不晚于入场冻结的预测支持截止点与风险持仓截止点的较早者，等待、修复及停机不重置期限。合法触发不等于实际退出收益达标：两种频率分开记录，退出滑点、失败、耗时及未闭合风险仍进入 Pi_plan 与执行风险验收。

开仓前概率不足或证据不足则不入场；进入 Holding 前不合格则按既有价格/次数/期限受控退出。Unknown 先对账，不以普通持仓资格判断取代未知敞口处理。进入 Holding 后，本门槛不因单次概率下降新增提前退出动作，继续原固定止盈、止损、到期及模型预警/失效规则。已进入 Exiting 不因概率回升恢复持仓。

P_exit 从周期已实现交易损益、剩余头寸按深度估计的平仓损益、实际费用及资金费，减预计退出成本得出。现货库存按账本成本归因，现货余额和头寸不得重复计价。实际成交价已含价格影响时，滑点只做归因，不再重复扣费。未知费用或估值不能按零处理；安全退出不以正收益为必要条件。

算例：入场参考收益 Pi_reference=10 USDT，alpha=0.8，最低目标2，则 TP=8；若实际计划 Pi_plan=6，准入和排序用6。金额门槛为5且其他门槛均合格时可入场，门槛为7则拒绝，不用参考10替代，也不把目标改成4.8。入场后 P_exit=3 时继续持有，P_exit=8.2 时发起退出，即使模型仍预测进一步回归。实际退出可能仅获7.7，记录执行偏差，不宣称锁定8。若先发生止损或到期，则不等待8。

盈利优化以完整策略样本外净收益为主要比较指标，在预先规定的回撤、尾部损失、敞口和时限约束内，联合比较目标比例、模式、数量和资金分配。收益包含失败、修复及尾差；停止交易期间的零收益也进入完整策略评价，错失机会另列诊断，不把假想利润作为账本损失再次扣除。不只统计成功周期，不在最终测试集反复挑选参数。

追踪止盈、达到目标后继续持有、分批止盈及动态上调目标均未获批准；只能作为未来比较候选，不默认为“盈利最大化”的实现。

## 9. 退出、尾差及重新触发

两种模式均以有价格保护的限价 IOC 退出。正常止盈和紧急退出各有版本化价格、次数和时限，均不无限追价。退出发单后不重新开回已平仓位，剩余量扣除未完成订单。PortfolioReduceOnly 与适用的 VenueReduceOnly 同时检查，不能穿零。

无法在价格边界内完成则保留未退出风险、停止相关新增风险并升级。Unknown 进入查询流程。亏损限额是触发线，不是实际损失保证。

现货小额尾差先查合法减仓能力；确不可单独清理时，完成订单及经济对账、无 Unknown 且单笔/累计/时限均合格，才显式承接为同组合残余库存。周期可标记完成且含残余，但账本不清零，仍计净值和风险。永续残仓不豁免。

正常结束、正常到期或无成交撤单：闭合、冷却、信号重置及再次越阈值后可再入场。止损、模型失效、对账异常或修复失败：复核并显式恢复后仍须重新触发。策略日损失、回撤及重启锁存优先，不因模型健康恢复解锁。

具体迟滞、连续点数、冷却起点、监测窗口及原因范围见 [S5 信号与监测合同](signal-monitoring.md)。冷却后重新取得有效重置证据；缺口不补点，旧越阈值不补发。

用户已确认：重新触发后若尚未成功预留且未发单，可在同次信号固定有效期、有限次数及重评间隔内重新计算完整候选；资金占用、排序未选中或推荐过期不必立刻永久丢弃该次机会。重评不得延长机会期限，当前信号/资格失效或次数/期限耗尽后须重新重置及触发。预留结果未知先按原身份核对，不另开周期；成功预留即消费信号，后续失败和恢复均属于原周期。

模型预警按合格连续坏窗口触发，连续健康证据可以解除预警；失效保持锁存，须复核和显式恢复。两者与周期执行阶段、证据资格及其他风险锁存分别保存。Warning中的健康持仓继续原计划；InvalidLatched启动受控退出，Unknown仍遵守原安全流程。S3单次概率下降不直接作为新的退出条件。

## 10. 状态与事件优先级

以下是策略周期状态草案，不替代核心订单状态：

| 状态 | 主要责任 | 允许的下一步 |
|---|---|---|
| Observing | 预热、资格检查、信号重置 | Candidate |
| Candidate | 模式、数量、资金排序及核心准入 | Entering 或丢弃候选 |
| Entering | 原目标内执行及对冲 | Holding、Repairing、Reconciling、Exiting |
| Repairing | 有限补齐或减掉多余部分 | Holding、Reconciling、Exiting |
| Holding | 固定退出计划及风险检查 | Exiting、Reconciling |
| Exiting | 只减少剩余原仓位 | Reconciling、Settling |
| Reconciling | 保存风险范围、查询事实 | 经资格检查返回原阶段或 Exiting |
| Settling | 终态、费用、尾差承接及对账 | Completed |
| Completed | 释放周期占用，保留历史及残余风险 | 冷却与重新武装 |

停机/预警是独立资格状态；进入它们不能丢失原执行阶段。事实先被核心应用，再决策。相同可见状态下：安全权限及 Unknown 约束优先，其次硬风险退出、模型失效/到期退出、正常止盈、修复、新入场。不存在有效行情时不凭旧价格计算正常止盈。

计时草案：预留生命周期从首次预留计；执行总时限从首次发单计；持仓风险时限从最早已证实经济成交计，事实不确定时采用保守已持久化边界。挂单等待、修复和重启不能重新起算。具体跨机时间证据及重启时钟校验必须在实现设计中确定。

## 11. 持久状态与配置

核心持有订单、唯一已应用成交总计、余额、风险预留和对账事实；OMS 报告累计量不能代替经济 Fill 累计量。策略私有状态保存周期关联、冻结计划、模型状态、信号重置及计时证据引用，不创建第二套权威余额。

周期、品种占用、残余库存及锁存的持久化归属必须通过源码接口核对；本草案不宣称现有核心已支持这些策略能力。重启先恢复并对账，处理遗留挂单和迟到成交，停机时间计入期限，所有资格满足后显式恢复新开仓。版本切换遵守既有 CutoverDrain/CutoverBarrier，不覆盖存量经济事实。

字段、规范编码要求、恢复顺序及公共接缝向量见 [S6 状态与恢复合同](state-recovery-contract.md)。恢复须保留冻结目标、机会期限/次数、意图身份、退出原因及各类锁存；不发布历史重放意图，不以旧checkpoint授权新交易。核心H3负责实现并验证，不以文档代替运行证据。

## 12. 验收矩阵

| 场景 | 必须观察到的结果 |
|---|---|
| 同本金不同深度 | 可选数量不同；无合格数量时不交易 |
| 基础币扣费及不同合约乘数 | 净敞口与合法数量匹配，尾差可解释 |
| 重复/乱序 Fill 与累计报告 | 不重复入账、不重复对冲，不混用累计口径 |
| 同一资金的多个候选 | 核心预留后重算，不双重占用 |
| A/B 与 A/C 共享同账户品种 | 只准入一个活动配对 |
| maker 撤单途中成交 | 处理迟到成交后再挂替代单，目标不扩大 |
| 一腿成交、另一腿 Unknown | 保留敞口区间与预留，不盲目重发 |
| 已知 1 对 0.6 部分成交 | 有限修复或减去 0.4，不追原目标余量 |
| 修复或退出中再次 Unknown | 转查询且保留原阶段，不重复减仓 |
| 正常止盈目标 8、可退出收益 8.2 | 触发退出，不为追求更高利润延期 |
| 参考收益10、目标8、实际计划收益6 | 准入、数量、模式及排序用6；门槛不满足就淘汰，不回算目标 |
| 两候选参考收益高低与实际计划收益高低相反 | 在其余约束/资金/时长相同时按实际计划收益排序 |
| 收益合格但开仓概率保守下界不足 | 不入场；不降低目标或概率门槛 |
| 入场/修复后持仓概率证据不足 | 不进入Holding，按既定规则受控退出；Unknown先对账 |
| 已在Holding且单次概率下降 | 不新增提前退出动作，原风险/到期/模型规则仍生效 |
| 止盈触发报价8.2、目标8、实际退出7.7 | 触发成功与实际收益未达标分别记录，实际净收益为7.7 |
| 原目标8、匹配一半、绝对下限2 | 持仓目标一次冻结为4，退出中不再次缩放 |
| 上例已发生修复净损失1 | 目标仍4，剩余净贡献须达5；不得因损失降目标 |
| 原目标8、匹配10%、绝对下限2 | 目标为2；若原计划下不可达则退出，不延长持仓 |
| 先止损/到期再达到目标 | 安全退出已锁定，不恢复持仓 |
| 无效行情或尚未到期预测标签 | 不生成正常信号，不伪造监测样本 |
| 收入为正的预测资金费 | 不使原本不合格机会通过准入 |
| 小额现货残余与永续残余 | 前者按限额承接，后者阻止周期完成 |
| 停机、跨日、重启、充值 | 不重置风险锁存或隐藏损失 |
| 重启时已有订单及过期周期 | 恢复原身份与期限，先对账及受控退出 |
| 仅有盈利模型无执行资格 | 不下单；双 IOC 合格不授予 maker 资格 |

验收分数据/样本外研究、事件回放与故障注入、只读影子、另行授权的受限真实验证。Demo 不证明实际收益；影子不证明真实排队成交率。每一模式独立合格，放量不得由单次成功自动触发。
