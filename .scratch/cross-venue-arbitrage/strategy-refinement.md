## S1 已确认：部分成交后的固定净目标

状态：用户已选择“按成交比例缩放，保留绝对下限，不因亏损再降目标”。已成为合同规则；不等于通过实现验收。

本次补齐既有合同的两个分支：绝对目标下限不缩放；修复亏损不导致再次降低净目标。

确认公式：

    r = q_matched / q_entry_target, 0 < r <= 1
    TP_holding = max(TP_abs_min, r * TP_entry)

这里 TP_entry 是入场前已经冻结的完整目标净金额。`TP_abs_min` 沿用该周期入场配置，不缩小；收益金额按合同精度规则处理。若 q_matched=0 则不进入 Holding，走撤单/对账/完成流程。

该目标只在入场及有限修复结束、订单成交已核实且不存在 Unknown 后确定一次；Holding 后不再缩放。所有已发生费用、资金费和修复净损失均进入整个周期的 P_exit，不从 TP_holding 再减去以降低赚钱要求，也不再重复扣除。

若 `R_done` 表示周期已完成部分的实际净损益，`U_exit` 表示剩余头寸从其账本成本到退出的预计净贡献（与 R_done 无重复费用），则：

    P_exit = R_done + U_exit
    U_exit_required = TP_holding - R_done

这不要求扩大原价格目标或延长持仓。按冻结计划、实际成本及剩余期限验证可达性；不合格则受控退出。目标可达性的统计判据在 S3 细化，不能把“可能达到”当作盈利保证。

| 示例 | 目标推导及结果 |
|---|---|
| 原净目标8，匹配一半，绝对下限2，无额外损失 | 新净目标4；整个周期可退出收益至少4才正常止盈 |
| 同上，已发生修复净损失1 | 目标仍4；剩余净贡献须达5，不能把整个周期净目标降为3 |
| 同上，某路径剩余净贡献4.5，已实现损失1 | 该路径净3.5未触发目标4；总体资格由S3概率判断，不以均值不足替代；不放宽目标或期限 |
| 原净目标8，仅匹配10%，绝对下限2 | 目标为2而非0.8；若达不到则不保留小额持仓等待 |

未采用的备选：保持完整原目标8而不按匹配比例缩放。不得在运行时切换到其他目标计算规则。

## 共同口径

- 周期 PnL 从首次经济成交起覆盖失败、修复、费用、资金费与残余，不能在进入 Holding 时重新从零记收益。
- 模型、alpha、价格目标规则、最晚时限及亏损边界沿用入场冻结版本；部分成交不是重新搜索参数的机会。
- 已触发风险退出或已处于 Exiting 时，不运行 S1 来恢复持仓资格。
- Unknown 必须先核对，不将“已知匹配部分”视作可以忽略未知剩余订单的充分条件。
- 表中金额只用于解释行为；不作为运行默认值，不表示已验证可达性。

## S2 已确认：参考收益生成目标，实际计划收益决定准入

状态：用户已选择“参考收益定目标，实际计划收益做准入和排序”，合同第 3/4/5/8 节已同步。S1 不受影响。以下计算顺序作为规格依据；参考政策及误差估计的研究实现仍需校准验证，S3 可达性未一并批准。符号是策略计算字段，不新增权威账本概念或核心架构。

### 问题与行为取舍

原草案用 Pi_cons 同时表示完整策略净收益和固定止盈目标的生成依据。但完整策略收益又取决于止盈目标，形成 `Pi_cons → TP → Pi_cons` 的循环。若先按可回归收益10生成目标8，却仍按10选择数量/排序，可能高估实际获利能力；若反复用实际收益回算目标，又可能无规则地降低目标直到通过准入。

已确认将目标生成参考收益与实际计划收益分开计算。两者都含完整成本和失败情形，但退出政策不同，不能共用名称或校准残差。参考模拟仅帮助生成目标，不授权实际策略持有到参考期限。

### 确定计算顺序

1. 固定当前可见状态、方向、模式、候选 q/挂价、模型及校准版本、h、alpha、费用、执行与风险边界；生成一组有固定身份和权重的联合市场/执行场景。q 指原计划匹配目标数量。
2. 运行版本化的参考退出政策：不使用尚未定义的净止盈目标；最多评估到本次决策时刻加 h，且不得晚于既有持仓风险期限。硬风险、模型失效、部分执行处置、Unknown、价格保护及费用规则仍生效。进入参考期限边界仅触发退出，不假设已平仓；未闭合风险仍保留。该政策在研究/校准前登记，不能逐候选更换以抬高参考收益。
3. 计算 `Pi_reference = E[Y_reference] - B_reference`。B_reference 仅覆盖参考评估尚未包含的不确定性，不重复扣成本。参考结果非正、证据不合格或缺少可解释方向时，不生成可交易候选，不能用正的最低止盈金额把负预测变成机会。
4. 一次计算并固定 `TP_entry=max(TP_abs_min,alpha*Pi_reference)`。记录参考政策、输入与结果。不得将后面的 Pi_plan 回灌重算这个目标。
5. 在相同外生场景及权重上重新运行真正的固定止盈策略：首次符合 P_exit 判据即触发退出，计实际执行结果，硬退出优先；部分成交按已确认 S1 生成 TP_holding，再验证持仓资格。参考与实际模拟的订单/队列/资金消耗状态各自独立，不能继承参考模拟的成交或占用。
6. 计算 `Pi_plan=E[Y_plan]-B_plan`。B_plan 按真实固定止盈政策的完整结果校准，不能直接拷贝 B_reference，也不能在 Y_plan 中再扣已计入的参考缓冲。
7. 只有实际计划通过金额、BP、风险、资金、能力及目标可达性门槛时才合格。原合同用于选择数量、模式和 Score 的 Pi_cons 明确映射为 Pi_plan；不以 Pi_reference 或 TP_entry 代替预期实际收益。
8. 核心事实变化或推荐过期时，未开始执行的候选作废并按新事实重新评估；执行开始后的模式、数量与退出计划仍按原合同冻结。不能把新候选评估用于覆盖存量周期。

为防止 S1 的“先确定匹配量、再验证可达性”产生模拟循环，第 5 步先在该场景执行入场及有界修复，得出已核对匹配量，再按固定公式确定该路径的目标；可达性评估只读当时可见状态与冻结预测器，不能偷看该路径后续是否成功。具体统计门槛及估计器由 S3 定义；未定义/未校准时，完整交易资格仍不成立。

### 公式与字段用途

    Pi_reference = sum(w_k * Y_reference_k) - B_reference
    TP_entry = max(TP_abs_min, alpha * Pi_reference)
    Pi_plan = sum(w_k * Y_plan_k(TP_entry, S1, fixed_policy)) - B_plan
    Pi_cons_for_admission_and_ranking = Pi_plan

| 字段 | 使用场景 | 禁止混用 |
|---|---|---|
| Pi_reference | 入场前生成固定目标；研究比较与解释 | 不能直接用于最终资金排序或宣称实际策略收益 |
| TP_entry / TP_holding | 整个周期净收益触发线 | 不是期望值或实际锁定收益；触发后仍有成交偏差 |
| Pi_plan | 净收益/BP准入、每模式数量选择及资金时间排序 | 不能回灌目标；失败时淘汰该候选 |
| P_exit | 当前有效盘口下预计立即退出的完整周期净收益 | 不是未来收益预测，不替代已发生费用事实 |
| 实际周期净收益 | 权威经济事实加明确残余估值后的结果 | 不扣预测缓冲，不把参考模拟损益计入账本 |

数值精度沿用合同：Pi_reference/Pi_plan 的预测净收益保守取整，目标金额按预登记精度固定；实际已发生费用及残余不因预测取整被清除。资金费未来收入在两种准入模拟中均按零，实际验证收益仍按真实收付。

## S3 已确认：收益与目标触发概率双门槛

状态：用户选择“采用双门槛，按上述阶段检查”。可达性口径、检查时机与失败动作已同步合同，沿用 S1/S2。数值门槛、估计算法的校准有效性及运行验收尚未完成；行为确认不授予交易资格。

### 本次行为选择

开仓前同时检查实际计划净收益及风险准入、目标触发概率的保守下界。入场/有限修复结束准备进入 Holding 时，根据已确认匹配量、实际成本及剩余期限，检查持仓资格与目标触发概率；不合格则按既有规则受控退出。已有净收益/风险门槛不因概率较高而放宽。

新增概率门槛只作用于这些阶段边界。进入 Holding 后不因每次预测概率下降而另增提前退出规则；继续固定止盈、硬风险、到期和模型失效规则。统计恶化由已确认的模型预警/失效流程处理。这样不会把可达性复核悄悄改成动态止盈或逐秒止损。

未采用的备选：不增加独立概率门槛，仅依赖 Pi_plan 和既有风险约束，概率作为诊断。运行时不得退回此备选以绕过证据不足。

### 触发事件与时间窗口

对待评估阶段 s 的每条场景 k，成功事件 H_k 定义为：

    存在有效决策时刻 u，在原计划允许的剩余机会窗口内，
    当前已匹配且具备正常退出资格，
    P_exit_k(u) >= 该路径固定净目标，
    且更高优先级的风险/模型失效/到期退出尚未触发。

这里 P_exit 来自有效可执行盘口、实际已付成本和预计退出费用，不是 mid 浮盈或预测价格。模拟按事件优先级处理同时触发：风险/到期优先，不能计为正常止盈成功。目标按 S1 在进入持仓前固定；进入 Exiting 后不重新寻找更高收益时点。

机会窗口结束不晚于入场冻结的预测支持截止点与风险持仓截止点的较早者。等待、修复、重启均消耗已用时间，不能在复核时重新给一整段 h。具体绝对时间证据由核心交接 H3 支持。窗口不足或已到期不能新授予 Holding 资格。

H_k 表示正常止盈被合法触发，不表示成交完毕或实际净收益达到目标。另列 `实际退出净收益>=目标` 的频率、触发至闭合耗时、执行偏差、未完成退出和尾部损失；这些进入 Pi_plan 与独立执行/风险验收。触发8.2、实际退出7.7时，目标8的触发事件为成功，实际收益达标事件为失败，现金结果仍记7.7。

### 开仓前与持仓前的概率分母

- 开仓前 p_entry：对整个候选计划的全部场景计算，不以“已经成交”筛掉零成交、部分后清理、拒绝和失败场景。零成交不是触发成功；部分成交若经 S1 合格并触发其固定目标，可计成功，同时保留数量分桶，避免少量成交掩盖整笔执行质量。
- 进入 Holding 前 p_hold：条件是当时已知的真实成交量、实际费用/修复损失、无 Unknown 及剩余期限；不重复乘一次已经发生的入场成交概率。使用已冻结模型及校准方法，根据当前有效输入更新条件分布，不重新训练或改目标。
- 两阶段分别校准 `p_entry_min`、`p_hold_min`；不能把两种不同分母的概率混成一个“胜率”。门槛随版本预登记，部署前必须完整，不能为某次机会临时降低。
- 持仓前经济检查沿用原持仓资格及完整周期成本口径，不机械复用原目标数量对应的开仓净收益金额门槛。该提案新增的是可达性门槛，不授权重新从零统计周期收益或扩大亏损预算。

### 估计与校准的研究算法

    p_raw(s) = sum(w_k * 1[H_k]), sum(w_k)=1
    p_cal(s) = frozen_calibrator(s, p_raw, declared_features)
    p_lower(s) = max(0, min(1,p_cal) - delta_cal(s) - delta_MC(s))
    probability_gate(s) = evidence_qualified(s) AND p_lower(s) >= p_min(s)

校准器、特征桶和误差覆盖范围固定在版本中。delta_cal 为时间隔离校准段估计的概率高估余量，delta_MC 为尚未包含的有限模拟误差；两者覆盖不得重叠。此处是待验证的保守估计算法，不声称在任意漂移下都具有严格覆盖保证。无法给出合格余量时标为证据不足，不默认误差为零。

参考资料说明校准曲线比较分桶平均预测概率与实际正例比例，并要求足够样本；不能把曲线本身当作本策略时间依赖样本的置信下界。见 [scikit-learn calibration_curve](https://scikit-learn.org/stable/modules/generated/sklearn.calibration.calibration_curve.html)。本项目采用独立时间校准段、依赖块与模式/数量/剩余期限分层；门槛在验证段选择，最终保留测试段只验一次。

重复抽同一历史窗口生成一万条模拟路径，只能减少模拟抽样误差，不能声称获得一万个独立市场证据。必须同时记录独立历史块、有效样本、模型适用范围及数据质量。

成熟标签必须来自完整观察到的机会窗口或已确定的终止事件。尚未结束或缺失数据的标签标为待成熟/不可判定，不能当作失败或从统计中静默删除；资格检查记录覆盖缺失并采用保守处理，证据不足则拒绝该阶段资格。只有完整窗口内未触发的场景才能记为明确未达标。

历史影子不能观察自己未下单时的真实成交与反事实持仓结果；回放标签与真实成交标签分开标明，不把模拟成功率直接当作实盘校准。尤其 maker 仍需独立的真实成交与条件对冲证据。

### 避免复核自身形成循环或偷看未来

持仓前估计先假设“此时获准继续持仓”，评估固定计划的未来触发概率；不把当前待判定的门槛反复调用到同一个条件估计中。未来风险、模型失效及到期规则仍照常模拟。取得概率后本次 gate 只作一次通过/拒绝决策。

开仓前的 Pi_plan 和 p_entry 外层模拟要包含未来持仓前 gate 的实际行为：拒绝后退出的成本不能遗漏。在该未来时点评估 p_hold 时，只使用该时点的可见历史与冻结估计器，不读取外层路径之后是否达标。估计器/模拟随机流及工作量有界且版本化；超限返回证据不足。

### 阶段检查结果

| 阶段 | 概率不足或证据不足时 | 不变的约束 |
|---|---|---|
| 候选尚未开仓 | 不入场，记录概率/证据拒绝原因 | 不降低目标、门槛或风险预算来救候选 |
| 入场/有限修复结束，拟进入Holding | 持仓资格未通过，按既有价格/次数/期限受控退出 | 不延长持仓，不把退出失败视为平仓完成 |
| 已有Unknown | 先走对账，不作普通持仓准入判断 | 保留可能敞口与预留，不盲目对冲或重发 |
| 已在Holding | 本门槛不新增逐次提前退出动作 | 原固定止盈、硬风险、模型失效与到期保持生效 |
| 已在Exiting | 不再判断是否可以恢复Holding | 继续退出/对账，不重新开回已平数量 |
