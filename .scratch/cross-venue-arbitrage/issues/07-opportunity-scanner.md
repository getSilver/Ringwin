## Question

提供可单独只读运行的 Python 扫描模块，在观察范围发现白名单外配对并展示候选证据。

来源：[策略规格](01-strategy-spec.md)、[策略合同](../strategy-contract.md)、[算法验证](../algorithm-validation.md)、[参数合同](../parameter-contract.md)、[信号合同](../signal-monitoring.md)及[恢复合同](../state-recovery-contract.md)。2026-10-23 用户确认拆票；策略使用 Python。

## 完成条件

- [ ] 复用经济及预测评估实现，输出稳定配对身份、方向、建议模式、数量、收益风险、数据截止点、模型版本和有效期。
- [ ] 观察范围与交易白名单分离；发现、展示、刷新候选均不输出交易意图、不预留资金、不自行批准白名单。
- [ ] 按配对/方向/模式去重，旧候选失效；证据不足可显示待验证，不能显示已具交易资格；现货/现货仅观察。
- [ ] 经现有 Web 控制面承接候选展示，复用已有接入方式；端到端验证输入→候选→展示及过期/缺口行为。
- [ ] 同一规范输入在扫描与交易评估中产生相同计算口径，数学基准沿用前置票；固定版本的扫描回放可复现。
- [ ] 保存实际命令、输入/版本、结果及局限；未执行项明确标记。公式正确、统计有效和运行资格分别给证据。
