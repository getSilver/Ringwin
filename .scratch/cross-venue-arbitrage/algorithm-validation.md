# 算法、校准与核心接口验证草案

更新日期：2026-10-20。归属：[规格访谈](issues/01-strategy-spec.md)，行为依据：[策略合同](strategy-contract.md)。

本附录把已确认行为展开为可实现、可复算的研究算法候选；不表示参数已校准、接口已具备或验收已通过。技术候选可以离线比较，不能借参数选择改变固定止盈、最大持仓、止损、独占及 Unknown 行为。本文中的计算记录名称是规格字段，不是新增核心领域概念。

## 1. 可复现输入与产物

每次评估保存 `StrategyInstanceIdentity / StrategyCursor / ConfigVersion`、稳定配对身份及方向、模型/校准/执行模拟版本、两腿行情序列和接收时间、InstrumentRules、费用及资金费证据、资金与风险事实引用、候选数量/价格集合、淘汰原因及最终排序键。记录模型所见截止点与模拟成交所用后续事实，不能混成一个时间戳。

研究清单另含数据文件摘要、代码版本、随机种子、依赖版本、训练/校准/验证/保留测试区间、预登记搜索空间、风险硬约束和运行失败记录。固定输入和版本必须给出相同候选、序号及退出原因；参数未填或证据过期不得输出可执行建议。

一秒网格 t 只使用接收时间不晚于 t、核心已经准入的最后有效双腿盘口；不使用事后修复行情。标签 `S(t+h)-S(t)` 在 t+h 的有效网格形成后才成熟；缺失标签单列，不填零、不以其未来是否缺失决定 t 时是否交易。策略模拟遇到后续缺口照常执行健康规则并保留风险，不能删除该周期。

## 2. 预测算法候选

统一记 `S_t=ln(mid_B/mid_A)`；d=+1 表示多 A 空 B，d=-1 表示空 A 多 B。方向收益指示量为 `d*(S_t-S_future)`，它是无量纲统计量，不是 USDT 盈利。现货方向仍受合同限制。

### 2.1 滚动基线与 AR(1)

滚动基线在最近 W 个连续有效一秒点上计算均值、样本标准差与 Z-score。预测使用训练资料中相同偏离桶、波动桶、方向和期限的已成熟后续变化均值；桶边界、最少样本及窗口在校准前冻结。空桶不外推为完全回归。

AR(1) 研究候选按 `S_i=c+phi*S_(i-1)+epsilon_i` 对连续相邻点做最小二乘。参数离线拟合并随版本冻结，在线只更新观测/诊断状态；不得暗中每日重拟合。首轮候选限制 `0<phi<1`，不满足时该候选不合格，不能把估计值硬裁到合格区间。

    mu = c/(1-phi)
    E[S_(t+h)|S_t] = mu + phi^h*(S_t-mu)
    Var_h = sigma_epsilon^2 * (1-phi^(2h))/(1-phi^2)
    half_life_seconds = ln(0.5)/ln(phi)

h 按一秒步数计算。Var_h 是模型内部诊断量，不包含参数误差、执行和资金费风险，不能直接作为完整交易区间。均值附近、近单位根、退化方差及样本不足都必须有拒绝原因；phi 极近 1 时使用稳定数值实现并测试，不能依靠溢出后的数值继续排序。

### 2.2 动态中心挑战模型

研究候选明确为：

    mu_t = mu_(t-1) + eta_t
    x_t = phi*x_(t-1) + epsilon_t
    S_t = mu_t + x_t + nu_t
    z_t=[mu_t,x_t]', F=diag(1,phi), H=[1,1]

Q、R、phi 和初始状态分布仅在训练阶段估计，约束 Q 半正定、R>0、0<phi<1；使用多起点拟合并报告参数可识别性及退化解。单独漂移中心不构成回归证据。在线仅做 predict/update，使用 Joseph 形式更新协方差并检查有限值、对称性及非负性。不得使用 smoother 状态产生历史信号。

预测均值为 `mu_filtered + phi^h*x_filtered`，协方差按 F、Q 逐步传播，并在观测预测中加入 R。训练结束后的验证继续仅使用当时观测过滤；不能从验证末端反向初始化。

首轮缺口候选为清空连续观测窗口并从版本初始先验重新预热；连续有效点数、协方差上限及双腿健康均满足后才重新合格。该重置只影响预测状态，不清除周期、时钟、风险或信号锁存。是否采用此候选由离线证据确定，不把健康恢复等同于重新授权。

### 2.3 从预测到经济场景

仅预测 log 比率不足以确定两腿现金 PnL：同一个 S 变化在不同价格水平、价差及深度下结果不同。禁止直接用 `q*P_ref*预测log变化` 代替完整收益；该近似只能列为诊断。

首轮模拟候选使用训练段连续历史块：按冻结的偏离/波动/流动性桶匹配，抽取两腿共同价格变化、预测残差路径、盘口形状、资金费及延迟/成交结果的联合样本。对每个历史起点 i，保存当时预测路径及 `e_i(u)=S_(i+u)-S_hat_i(u)`，当前生成 `S*(u)=S_hat_t(u)+e_i(u)`；用同一块的 A 对数收益路径得到 `P_A*(u)`，再令 `P_B*(u)=P_A*(u)*exp(S*(u))`。盘口价差与深度按同一块相对价格/数量形状映射，再依规则取整。

这是一种待验证的条件残差模拟假设，不能证明未来流动性或成交概率。桶匹配、价格尺度和数量尺度适用范围须由外层验证检查；超出范围、缺少联合观测或样本不够则模式不合格，不能拆成相互独立的填充率和对冲成本来补数据。模拟时间步应足以覆盖对冲延迟；一秒研究网格不能代替事件级执行路径。

每条场景运行同一固定退出计划、部分执行/Unknown 规则和资金约束，获得 `Y_k=完整周期净收益`、峰值占用、未对冲峰值、持有/对账时间及触发原因。未完成尾部不能作为零损益或成功周期；研究窗口须延长到闭合或以明确未解决风险及保守估值报告，资格不因截断而改善。

## 3. 成本及执行算法

### 3.1 深度、手续费与资金费

对买单按升序卖档、卖单按降序买档遍历；每档取 `v_j=min(剩余量,可用量_j)`，累积 `sum(p_j*v_j)`。价格越界或证据深度不足即停止，返回可成交量与未成交量，不能用最优价填满剩余量。可用量折减只能来自校准版本；不得凭空补足盘口。

延迟模拟在订单预计到达时的场景盘口撮合；当前静态盘口成本、延迟损失和实际成交价中已经包含的冲击不能重复扣减。相同历史盘口被多个模拟订单消耗时维护剩余量，不能重复使用。市场冲击超出历史可验证数量区间的候选不参与排序。

费用逐笔依据 maker/taker、费率、扣费资产及舍入规则计算，买入基础币扣费后再配对。第三币手续费须有当时有效估值和可支付余额，不得当作免费；返佣未获确认不改善准入。实际账本包含真实返佣。费用与残余资产估值使用不同字段，防止净数量减少与手续费金额重复计损。

资金费准入对每个可能跨越的结算点计算 `max(0,方向对应的支付率)*场景名义金额`，求逐腿支出之和；预计收入按零。支付率上界来自训练与校准，不把当前费率恒定外推到所有期限。正常期限、最晚风险退出期限分别预算；触线后未退出的延迟压力情景独立报告，不能假设最大持仓时刻必已成交。实际研究收益和账本采用真实收付。

### 3.2 Taker–Taker

场景从共同决策时刻出发，分别模拟两腿发送/到达/回报延迟、价格保护 IOC 的成交量和拒绝。联合延迟样本保留拥塞相关性。根据实际已确认量和在途可能量执行合同修复规则，不把两笔各自成交率相乘当作配对成功率。

### 3.3 Maker–Taker

每次报价在固定数量和有界价格集合内评估完整周期 Pi_cons：买挂单候选为 `best_bid-k*tick`，卖挂单为 `best_ask+k*tick`，k 来自预登记非负整数集合；必须原生 Post-only、合法且未越计划价格边界。该集合是首轮研究基线，不代表排除未来经验证的其他报价算法。

研究队列基线：到达时将可见同价队列放在前方，只有经核对的主动成交量可以消耗前方数量；无法识别的撤单不假定发生在我方前方。隐藏量及撤单位置作为压力场景。L2 无法观测真实排队位置，因此该模型不能单独授予 maker 资格；需独立真实成交数据校准成交率、成交后不利价格变化及对冲成本。只读影子不能补出此证据。

按成交条件与等待时长联合评估：全成、部分成后撤单、零成交、对冲失败、撤单途中成交、Unknown 均有场景概率和经济结果；权重和为 1，稀有失败不能因样本未出现而直接设为零。使用预登记压力情景和最大失败预算补充约束，压力权重不伪称经验概率。对冲使用唯一已应用 Fill，减去在途可能对冲量，并保留区间；不重复对冲。

新挂单选合格 Pi_cons 最大的价格，并列选侵略性较低者、再按价格 tick 确定排序。只有间隔、次数、总寿命及改善门槛满足才普通换价；安全撤单立即进入安全流程。撤旧终态与成交核对前不能发替代单。此规则须以回放与校准比较验证，不能用提高成交率为理由放宽原边界。

### 3.4 保守收益与缓冲去重

    mean_Y = sum(w_k*Y_k)
    Pi_plan = mean_Y - B_model - B_execution

本附录保留的旧符号 Pi_cons 仅为 Pi_plan 的同义记号，均表示实际固定止盈计划的保守收益；不用于生成目标。Y 和上述缓冲对应实际计划；参考政策另计算 Pi_reference 与 B_reference。

首轮 B_model 候选为校准段“模拟均值相对完整周期实际结果”的分块重采样单侧高估误差上界，截断下限为零；须在模型生成的实际候选选择流程之后校准，不能只校准随机抽取的容易样本。块长度不小于最大标签/周期依赖跨度，置信水平与样本下限预登记。样本不足不报零缓冲。

成本台账每项标记“已进入 Y”“由 B_model 覆盖”“额外 B_execution”之一。B_execution 只覆盖前两项未覆盖且有独立证据的执行误差上界；若校准已覆盖完整执行误差，不再另扣同一滑点分位数。分位数不能冒充期望值；尾部损失/最大单腿失败风险另外作为硬门槛，不声称 Pi_cons 是收益保证。

## 4. 数量、精度与确定排序

按规则将两腿可执行单位转换成基础资产有理数；现货扣费后数量与永续乘数共同决定匹配量。对每腿枚举合法整数 lots，并根据匹配目标向不扩大风险的方向取整，重新计算余额、残余、所有费用及收益。不能仅对两腿步长取最小公倍数而忽略扣费和非线性费用规则。

有限网格候选：冻结 K 个预算比例，加上盘口档位耗尽点和最小合法数量边界；以当前预算/深度上界投影到合法 lots，去重并按 lots 升序评估。集合生成算法、K 和最多候选数随版本固定；不能只评估最大数量，也不能假定收益随数量单调。超出计算容量返回明确不合格原因，不能截取先到的线程结果。候选的最大值仅指此有限网格。

每个配对/模式先选 Pi_cons 最大的合法 q，再按合同 Score 逐个预留重算；预留失败刷新事实，不重试旧候选的余额快照。保守 T_occupancy 使用校准样本完整占用时间的预登记上分位数，包括失败及对账；未闭合样本是右删失数据，不能丢弃后低估时长，无法给出可靠上界时不合格。

资产现金采用各 Asset 原子单位；价格用 Instrument tick、数量用 lots，乘数用规则有理数。研究统计允许浮点，但拒绝 NaN/Inf；经济边界转换时收益向下、成本与预留向上取整。BP 和 Score 用整数交叉乘法比较，检查溢出，不依赖显示小数判断并列。禁止用研究浮点余额替代核心账本。

模型状态可重放精度仍是接口验收项：需固定运算顺序、量化方案、checkpoint 编码及误差预算，并证明恢复前后意图相同。既有 PortableStrategyStateJsonV1 不允许任意浮点，不能直接序列化 NumPy 对象或绕过摘要。未完成此验证不得声称模型已接入恢复链。

[S6状态与恢复合同](state-recovery-contract.md)已细化模型专用字段、规范编码与数值一致性要求，并给出S6-A至S6-P公共接缝验收。该合同是实现输入，不代表恢复验证已执行。

## 5. 校准协议与监测

字段单位、合法范围、精度、生效/过期及校准产物验收见 [S4 参数合同](parameter-contract.md)。本节研究参数必须解析为该合同中的明确值或版本引用，不得将未校准示例值自动设为默认配置。

1. 先登记风险硬约束、参数搜索空间、数据可用性与失败处理。风险额度是外部约束，不和收益一起优化到更宽。
2. 按时间建立训练、独立校准、选择验证和最终保留测试段。滚动外层评估每折只用此前资料；同一时点所有配对保持同一分区，防止共享市场信息泄漏。
3. 训练拟合预测与执行条件模型；校准估计覆盖误差、保守成本及占用时长；验证选择模型、h、alpha、网格及报价规则。校准/验证的每个预测只能使用生成时已成熟的标签。
4. 在分界处剔除标签或完整交易评价区间跨界的训练起点，并设置不短于预登记最大评价跨度的时间隔离。仅做一行 `TimeSeriesSplit` 不能自动防止交易生命周期泄漏。历史特征窗口可以合法读取分界前当时已知数据。
5. 统一在完整策略资金曲线上选择约束内净收益最大的候选；报告多次尝试数、逐折收益、回撤、尾损、资金占用、模式/数量覆盖、拒绝与故障占比。稳定性不足或全部不合格则只观察，不强选冠军。
6. 冻结最终版本后只做一次保留测试；失败后的修改属于新研究版本，原测试段成为已见数据，须有新的未见区间。扩大搜索次数不能隐瞒。

目标使用净资产变化减外部净分配流量：

    PnL_strategy(t0,t1) = NAV(t1)-NAV(t0)-NetExternalAllocation(t0,t1)
    E_adj(t) = NAV(t)-累计外部净分配(t)
    Drawdown_abs(t) = max_(u<=t) E_adj(u)-E_adj(t)

NAV 含实际费用、资金费及仍存残余库存，现货库存只计价一次；预留不算费用。日损失以配置时区日边界的 E_adj 变化计算，日边界不解除锁存；相对回撤如使用，须另声明正的基准资金分母，不能除以可能为零的调整后净值。模拟停止交易时现金收益为零，其错失机会单列诊断，不能再把假想盈利扣入真实 PnL。这样保留停机对整体收益的影响且不捏造账本损失。

用户已确认[S2 分阶段计算](strategy-refinement.md#s2-已确认参考收益生成目标实际计划收益决定准入)：先按冻结参考政策估计 Pi_reference，再一次计算 `TP_entry=max(TP_abs_min,alpha*Pi_reference)`，最后模拟实际固定止盈计划并估计 Pi_plan。准入、数量、模式及资金排序均用 Pi_plan，不反向修改目标；未过门槛则淘汰。参考与实际计划的误差分别校准，不能重复扣缓冲。部分成交按已确认 S1 处理，不能运行时重选 alpha。

目标可达性采用[已确认 S3 双门槛及阶段检查](strategy-refinement.md#s3-已确认收益与目标触发概率双门槛)，不以 Pi_plan 与 TP_entry 的大小关系代替。S2-A 至 S2-F、S3-A 至 S3-I 的预期已确认，研究校准和策略运行验证未执行。

| K、报价 k 集合、改善门槛、批次与 T_floor | 有界容量及验证 | 丢弃率、重算一致性、资金公平性 |
| 数据时效、预热、监测窗口/阈值 | 数据质量及独立监测校准 | 缺口恢复、误警、漏报及持续性 |

模型监测以成熟预测为单位，维护方向误差均值、预测区间覆盖、输入桶越界率、到期退出率。为避免伪独立，首轮监测按固定相位每 h 秒取一个不重叠期限标签，再以块方法评估剩余相关性；有效样本不足标为证据不足。预警/失效分别配置门槛、最小样本和连续窗口数；解除预警另用较低门槛和健康窗口数。失效保持锁存；硬数据/权限失败不等待统计窗口。具体数值未校准，不提供可交易默认值。

窗口去重、证据不足时连续计数、模型转换动作、信号迟滞和有界重评遵守 [S5合同](signal-monitoring.md)。算法验证必须包含全部机会重评及拒绝成本/机会影响，不能只保留最后被选中的候选并隐去评估次数。
