# S5 信号重新武装与模型监测

状态：行为规则已整理；用户已确认同次信号内允许有界重评，数值校准和运行验收未执行。

归属：[策略规格](issues/01-strategy-spec.md)。依据：Q33信号重置、Q37模型分级、[S3阶段检查](strategy-refinement.md#s3-已确认收益与目标触发概率双门槛)及[S4参数合同](parameter-contract.md)。本文件中的状态名是策略私有状态的规格字段，不新增核心权威类型，不改变固定止盈、止损、持仓期限或 Unknown 权限。

## 1. 分开记录四组状态

| 状态维度 | 含义 | 不允许的混用 |
|---|---|---|
| 周期执行阶段 | 合同的Entering/Repairing/Holding/Exiting/Reconciling等 | 预警、暂停不能丢失当前订单与执行阶段 |
| 模型状态 | Normal、Warning、InvalidLatched | 行情恢复不等于模型正常，模型正常不解除其他锁存 |
| 证据资格 | 是否有足够、成熟、适用且有效的行情/统计/校准证据 | 样本不足不是模型成功，也不自动等于模型失效 |
| 信号武装进度 | 冷却、等待重置、等待越阈值、有界评估中、已被周期消耗 | 信号存在不授予核心交易权限 |

异常原因按集合保留，不能只有一个会被覆盖的“暂停原因”。同一时刻按核心事实顺序先处理安全/Unknown、风险、模型失效/到期、正常止盈，再处理修复和新候选。S3概率检查只在已确认阶段执行，不把每次 p_hold 下降伪装成模型失效。

## 2. 信号输入与迟滞

每个已授权配对方向使用一个版本化 `signal_score`，分数越高表示该方向偏离越强。其定义、单位及数值精度由 `signal_score_ref` 指定，例如基线模型的有方向标准化偏离；不可让不同执行模式或候选数量各自制造独立的“新信号”。该分数只用于重置/触发，收益、概率、资金和执行资格仍由S2/S3及核心判断。

配置 `reset_threshold < entry_threshold`，并分别规定连续有效网格点数 `reset_confirm_points`、`entry_confirm_points`。每个有效一秒网格点最多计一次；重复消息不多计，迟到信息不修改旧网格。

- 重置成立：连续有效点的 score 均 `<= reset_threshold`。
- 越阈值成立：在已完成重置后，观察前一有效点 `< entry_threshold`、当前点 `>= entry_threshold`；再连续满足 entry_confirm_points 个点。该计数包含首次越阈值点。
- 中间落回入场阈值下方，则入场确认计数归零，仍可等待下一次真实越阈值；不能仅因计数时间到了而触发。
- 无效/缺口点不计数，不把缺口两侧当连续。失去信号观测资格后清除未完成确认与未消费的候选资格，恢复后重新观察重置及越阈值；不清除周期、既有订单、损益、次数历史或风险锁存。

“信号观测资格”要求无活动周期、行情有效且模型Normal及证据合格、相关显式恢复/激活约束已满足；资金暂时不足不被当作行情无效，但仍禁止准入。数据恢复后的第一个高分点不能伪造跨越过程。首次启用没有可验证重置历史时，从等待重置开始；不补造激活之前的信号。

阈值只定义稳定可复算事件，不表示回归保证。模型不同允许使用不同已验证分数定义，但版本切换不复用不兼容的重置证据。

## 3. 冷却与重新武装顺序

正常完成、无异常到期或完全未成交撤单，先完成订单/经济对账及占用释放。允许的现货残余承接仍须满足原限额及持续风险规则；Unknown、未豁免残仓不能完成本流程。

以核心可证的周期闭合/占用释放事实形成 `closed_at`，冷却截止为 `closed_at + cooldown_ns`。该起点在同一周期只记录一次，迟到重复终态、定时器重复和重启均不能重新起算或缩短。跨机时钟证明属于H3。

冷却结束且信号观测资格满足后，重新收集重置证据，再等待越阈值确认。冷却期间的重置或旧高分不能缓存为冷却结束后的新机会。到期退出若同时有异常原因，按异常分支处理，不因“到期”覆盖异常。

异常周期在复核、对账及显式恢复前保持相关锁存；恢复不是立即入场指令。仍须满足已存在的冷却截止、有效信号重置及再次越阈值。不同原因的恢复证据只能解除对应原因；策略级风险锁存及重启恢复授权不能由配对级健康解除。

## 4. 同次信号内有界重评（用户已确认）

用户选择：“允许同次信号内有界重评”。

越阈值确认完成时，记录稳定的触发证据（配对、方向、信号版本、确认点序号）、固定 `opportunity_deadline`、累计评估次数与最近评估序号。身份由可重放证据派生，具体编码在S6确定；它不是OrderIntentIdentity或交易权限。

    opportunity_deadline = confirmed_trigger_time + opportunity_ttl_ns
    candidate_deadline = min(opportunity_deadline,
                             evaluation_time + recommendation_ttl_ns)

在以下条件全部成立时，可在同次信号内重新计算模式、数量、成本、S3、资金和排序：

1. 尚未成功建立周期预留，也未发出该周期订单；不存在可能已经预留/发送而结果未知的状态。
2. 原机会未到期，`evaluations_used < max_opportunity_evaluations`，距离上次评估满足固定最小重评间隔。
3. 行情、模型、授权和配置仍适用；当前分数仍满足入场阈值。分数跌回阈值下方或资格失效时，该机会失效并等待新的重置/越阈值，不以反复回升续期。
4. 每次重算完整资格，不能复用已经变化的余额、旧概率、旧费用或旧风险准入；同一模式独立资格要求不变。

资金暂时被占用、批次排序未选中或某份推荐过期，可以在该窗口内重评。初次评估计入次数；一个确定批次中的内部预留后重算受S4批次上限约束，并保存工作量，不能绕过总计算容量。时间/次数耗尽的机会不重建为同一信号的“新机会”。

核心明确拒绝且证明没有留下预留/命令时，可以在剩余机会范围内重评；若因新的锁存/权限失效拒绝，则先处理资格，不能绕过。核心返回未知、超时或证据不完整时，保存原请求身份并查询，不创建另一个周期来试探。

核心成功预留即消耗本次信号，后续属于同一周期；第一腿或任一后续订单发生未知/失败，按原修复/对账规则处置。即使后来全部未成交撤单，也须经过周期闭合、冷却、重置和再次越阈值，不能回收旧信号重开。

机会存续中只有执行前候选可以重算；尚未执行候选的预测期限可重新评估，但机会本身不得延长。执行开始后沿用原冻结目标、模式及周期时钟。重启不刷新机会期限或次数，且仍须原有显式恢复授权；S6负责证明无重复预留。

## 5. 模型监测的确定计算

监测指标均版本化，统一成“值越高越坏”的有界或明确量纲指标。例如方向预测偏差的绝对值、覆盖不足程度、输入分布越界率及回归到期率。每项定义 `metric_ref/window_ref/min_effective_samples`，不能只给一个无单位阈值。

预测误差与覆盖率只消费已成熟标签；预测仍未到期或标签缺失时保留待成熟/不可判定身份。到期率的分母包括有完整原因分类的相关周期，不把对账未完周期默认为正常完成，不将风险退出伪称到期。缺数据不能当作误差0或成功。

按版本固定的窗口推进边界计算，窗口有唯一身份与截止序号。同窗口重送、同事实重复、重放批次变化均不增加连续窗口次数。重叠窗口须按既定依赖块/有效样本处理，不能用一秒采样点数宣称独立证据。全部阈值和窗口计数来源于离线校准，在线不重选。

对每个指标j定义：

    clear_j < warn_j < fail_j
    bad_warn_j = qualified_j AND value_j >= warn_j
    bad_fail_j = qualified_j AND value_j >= fail_j
    good_j     = qualified_j AND value_j <= clear_j

连续预警/失效窗口数逐指标计数，任一已声明指标达到对应连续窗口门槛即可触发该级别；不把不同指标交替越线拼成一个指标持续恶化。失效优先于预警。并非每类指标都必须有两档数值阈值，但不适用档位须在schema中明确，不能把缺失当无穷大。

证据不足窗口不增加好/坏计数，不推进自动恢复；打断“连续合格窗口”的当前计数，保留历史指标及原因。独立证据资格关闭新增风险，当前Warning/InvalidLatched不因计数归零变成Normal。此为计数规则，不把样本不足自动定性为失效退出。

模型数值不变量破坏（非有限值、不可用协方差或不兼容状态等）按已批准的模型失效类别直接锁存，不等待统计窗口。一般行情缺口、校准到期、阈值未填属于独立资格不合格；除非已登记且验证的模型失效谓词同时成立，不凭该原因新增强制退出。相关规则未完整时配置不合格。

## 6. 状态转换与动作

| 当前模型状态 | 条件 | 下一状态及动作 |
|---|---|---|
| Normal | 任一合格指标连续满足warn，未满足fail | Warning；停相关新周期，撤销未完成入场挂单 |
| Normal或Warning | fail连续条件满足，或明确模型不变量失效 | InvalidLatched；锁存新增风险，启动受控退出；Unknown仍先核对 |
| Warning | 全部必需指标与独立证据连续满足恢复条件 | Normal；只解除本模型预警，重新观察信号，不清除其他锁存 |
| Warning | 样本不足、只部分指标恢复或仍有独立资格不合格 | 保持Warning，不累积恢复窗口 |
| InvalidLatched | 指标恢复但无显式恢复事实 | 保持InvalidLatched |
| InvalidLatched | 完成复核/必要重新验证、对账及明确恢复，所有恢复资格合格 | Normal；仍受其他锁存/授权及重新武装约束，不直接发单 |

Warning期间已有健康Holding继续原计划；入场挂单撤销后已有Fill仍须对冲/修复或退出，不能因暂停信号丢弃经济事实。警告不授权需要新增风险的补齐，任何动作仍须核心权限及原预算。

统计预警的解除使用全部必需指标同时满足 `good_j` 且连续达到 `clear_windows` 的证据，不用“至少一个指标好了”解除。当窗口边界不同，以固定监测评估边界引用各指标最新且未过期的合格窗口；未更新的同一窗口不能反复算成新的健康证据。

## 7. 锁存范围及恢复证据

| 原因 | 最小受影响范围 | 恢复条件 |
|---|---|---|
| 配对模型失效/普通止损/修复失败 | 该配对；关联共享风险依赖按事实扩展 | 对账、原因复核及显式恢复，再重新武装 |
| 账户对账异常/Unknown | 受影响账户及共享该风险资源的配对 | 权威查证及原异常恢复条件，不以超时或模型Normal替代 |
| 策略日损失/回撤触线 | 整个策略/VirtualPortfolio授权范围 | 原策略风险复核及显式恢复，跨日或充值不解除 |
| 进程重启/Host恢复 | 该Host/策略授权范围 | 原恢复屏障、对账/预热及用户显式恢复新开仓 |
| 模型Warning | 该模型实际适用的配对范围 | 合格连续健康窗口可自动解除，不解除上面任何一项 |

恢复记录至少关联原因、受影响范围、产生序号、复核证据与恢复授权事实。不得使用一个全局布尔值把多个原因全部清空；不要求在本会话选择新的核心控制接口，现有控制面与权威恢复合同继续适用。

## 8. S4字段补充及S6交接

需明确的版本化字段：

- `signal_score_ref / reset_threshold / entry_threshold / reset_confirm_points / entry_confirm_points`：同量纲阈值、严格迟滞、正整数确认点数。
- `opportunity_ttl_ns / min_reevaluation_interval_ns / max_opportunity_evaluations`：正时限、正间隔、有限正次数。初次评估计1，区间为 `[trigger,deadline)`。
- `monitor_metric_refs / monitor_evaluation_schedule / window_refs / metric_freshness_ns`：指标口径、唯一窗口身份、成熟/缺失标签规则和时效。
- `warn_threshold / fail_threshold / clear_threshold / warn_windows / fail_windows / clear_windows`：适用档位明确，计数为正整数，阈值按不利方向统一。
- `invariant_failure_predicates / recovery_evidence_requirements / reason_scope_map`：明确错误分类与既有权限引用；不接受脚本任意扩大范围或清除锁存。

[S6状态与恢复合同](state-recovery-contract.md)已纳入冷却起点、重置/越阈值进度、触发身份、固定deadline、评估计数及是否已消费；模型状态、各原因、唯一监测窗口游标、连续计数和未成熟标签身份也须可恢复。它们引用核心预留/成交/恢复事实，不复制权威账户余额。
