# S6 策略私有状态与恢复验收合同

状态：语义字段、恢复顺序和验收要求已成文；序列化实现、数值资格与运行验收未执行。

归属：[策略规格](issues/01-strategy-spec.md)。依据：[主合同](strategy-contract.md)、[S1–S3](strategy-refinement.md)、[参数合同](parameter-contract.md)、[信号与监测](signal-monitoring.md)。核心接口施工仍归[H3交接](issues/02-core-interface-handoff.md)；本文不选择新的存储架构或核心权威所有者。

## 1. 唯一所有者与读取边界

策略 checkpoint 只描述某个 StrategyCursor 上的 StrategyPrivateState。核心仍拥有订单、唯一已应用 Fill、账本、预留、账户品种占用、权限、对账及风险事实。策略保存它们的身份/版本/序号引用或可验证派生缓存，不能恢复一套“策略认为可用”的可写余额。

策略模型状态、冻结计划、信号及监测进度属于策略私有数据；风险锁存等若已有核心权威事实，策略只保存关联及已观察进度。模型InvalidLatched与策略异常处置原因保留至相应恢复事实，不能由读取checkpoint自动解除。恢复记录的“当时授权有效”不等于当前授权。

| 类别 | checkpoint保存 | 恢复后的权威来源 |
|---|---|---|
| 配对周期、模型、信号 | 下列显式字段及摘要 | 兼容checkpoint加连续规范输入重放 |
| 成交、成本、费用、资金费、残余 | 周期归属及经济证据引用；可选校验缓存 | 核心经济投影及可认证业务历史，不以OMS累计量替代Fill |
| 订单、发送、预留和占用 | 原身份、关联请求、已观察事实游标 | 核心持久事实、网关状态和Venue对账 |
| 权限/恢复屏障 | 引用及已应用游标 | 当前核心激活/撤权事实；旧会话包络无效 |

## 2. 元数据与规范编码

包必须绑定 StrategyDefinition、StrategyInstanceIdentity、ConfigVersion、state_schema/version、数值算法版本、StrategyCursor、next IntentSequence、模型/校准/执行模型内容哈希和StrategyStateDigest。恢复前逐项精确校验，不按“最新版本”替换。

沿用 PortableStrategyStateJsonV1：固定字段顺序、无空白、显式tag、有界数组和基础值，禁止任意映射、pickle、解释器对象及浮点JSON。整数身份和金额遵守schema编码，不经可能丢精度的通用浮点解析器。

可选字段必须由tag决定是否存在；例如 `target_pending` 不携带TP_holding，`target_frozen` 必须携带其冻结证据；`no_opportunity` 不携带活跃deadline。拒绝未知tag、重复键、超容量、非法单位及矛盾字段，不能忽略后继续恢复。

机会身份的语义元组固定为 `(StrategyInstanceIdentity, pair_ref, direction, signal_version, trigger_sequence)`，其中最后一项使用确认触发的 ShardSequence，不是HostBatchSequence。按schema中的有序字段编码；若实现使用摘要作为索引，原元组仍必须可核对，不仅靠截断哈希判断业务相同。

周期关联引用首次共同准入请求的稳定 IntentGroupIdentity/核心周期承接事实。修复与退出意图关联原周期，不能用新HostSessionIdentity生成新周期。具体H2预留事实编码由核心会话完成并与该关联对齐，不在策略内自行制造权威预留身份。

## 3. 必须覆盖的状态字段

以下为语义字段合同；实现可以分组编码，但不得遗漏语义或把必需数据藏在不可重放外部缓存。

| 分组 | 必需内容 | 不变量 |
|---|---|---|
| 输入/决策进度 | StrategyCursor、下一IntentSequence、最后完整应用输入身份/版本引用 | cursor不前移到未完整应用输入；无权重放仍确定性推进序号 |
| 周期关联 | pair_ref、方向、原组/预留关联、两腿账户/Instrument、活动阶段、Reconciling前阶段 | 每配对一个活动周期；Unknown不能丢原阶段 |
| 冻结计划 | 原净目标量及单位、模式、Pi_reference、TP_entry、alpha/绝对下限、原价格目标/退出政策引用 | 不以当前模型重算存量目标，不放宽原预算 |
| S1持仓目标 | pending/frozen标记、q_matched证据、TP_holding、冻结cursor及计算规则 | 进入Holding必须frozen；退出中不按剩余量重算 |
| 执行进度 | 原/替代/对冲/修复/退出意图关联、各预算已用次数、已观察终态/Fill游标 | 重复报告不增加经济成交或重复对冲；在途可能量不能消失 |
| 退出与异常 | 首次退出原因/序号、附加原因集合、当前Unknown订单引用 | Exiting不可因恢复或概率回升回到Holding；原因不互相覆盖 |
| 时间证据 | 首次预留、首次发单、最早经济成交、预测支持截止、退出/修复截止、来源时钟/核心事实引用 | 原起点及deadline不能因重启重置；不直接复用异机单调时间 |
| 冷却/信号 | 闭合事实、冷却截止、方向/score版本、最近有效网格、重置/越阈值连续计数、阶段 | 不将缺口或冷却期间旧信号补成新触发 |
| S5机会 | 原身份、固定deadline、累计评估次数、上次评估、消费/请求未决标记 | 重启不续期、不清次数、不回收已消费机会 |
| 模型 | kind、参数引用、在线更新状态、初始化/预热阶段、最后有效输入/网格 | 不把模型预热当成新周期，不能在恢复时自动重拟合 |
| 监测 | Normal/Warning/InvalidLatched、原因、各窗口唯一身份/游标、连续计数、恢复证据引用 | 重复窗口不多计；无成熟证据不计健康；恢复按原因隔离 |
| 待成熟预测 | 预测身份、生成cursor/截止点、h、模型/校准版本、预测值/区间及标签状态 | 不偷看未来标签；缺失与未成熟不记成功/失败 |
| 研究模拟进度 | 生成器/算法版本、固定seed或可重建派生材料、评估身份/已用预算 | 不用当前墙钟随机数；恢复不多一次“抽到更好结果”的机会 |
| 经济校验缓存 | R_done、实际费用/残余等可选派生值的来源引用与截止cursor | 只校验或重建，不覆盖核心账本；新事实到达后不能沿用旧值判定 |

重放要求模型专用状态闭合：

- 滚动统计：有序有效窗口、容量/有效长度、最后网格与缺口边界、算法所需累计量；若累计量可重算，重算次序必须固定。
- AR(1)：冻结参数身份、最后有效观测及诊断/预热窗口；恢复不重新拟合phi。
- 状态空间：filtered均值向量、协方差、滤波更新阶段、先验引用和最后观测；不能把smoother终值装成在线状态。

这些字段按明确最大配对数、活跃周期数、订单引用数、窗口长度和待成熟标签数有界。达到容量时不得删除未解决订单、未成熟标签或异常原因以伪造资格；关闭相关新增风险并按已有安全流程管理存量。历史回收须保留可认证引用、累计量及游标；策略不另造无限历史账本。

## 4. 数值一致性

现金、价格、数量、目标和门槛遵守S4的整数/有理数语义。模型中间值必须通过版本化 `numeric_codec_ref` 显式编码成PortableStrategyStateJsonV1允许的基础值；例如使用有定义scale的整数方案或无损的数值组成字段。具体位宽、scale、舍入及数学库选择留给H3实现验证，不在无证据时选“足够精度”。

核心验收标准是：相同版本、完整相同输入流，从中断点继续的模型规范状态、StrategyStateDigest及决策/意图序列与连续运行一致。若采用量化，连续路径也必须在同样的确定更新边界使用同一规则，不能只在保存checkpoint时量化。若编码无损但运行平台数学运算不同，仍必须证明支持平台上的收敛；编码一致不能代替数值资格。

数值误差研究可报告相对高精度参考的误差，但不得据此容许恢复后改变买卖方向、数量、目标、阈值比较或意图身份。不满足位级规范状态/摘要与决策一致的实现保持未合格；不得通过忽略协方差字段、清空窗口或更换seed来“修复摘要”。

拒绝非有限数、非法scale、负方差、越界计数、无效矩阵及不可表达金额。普通重启不是重新初始化模型的理由；确需Rebuild时按既有StrategyStateTransition及预热/授权规则执行，不能清除未结束周期。

## 5. 保存与恢复顺序

### 保存

仅在一个完整规范输入已应用后的StrategyCursor上截取自洽状态；不得在更新一半协方差、目标或意图序号时发布。内容编码、哈希、StrategyStateDigest与发布事实绑定同一cursor及版本。发布/持久顺序由核心H3实现，策略不能把“文件写完”视为StrategyCheckpointPublished。

恢复包必须可解析其依赖的冻结配置、模型、规则和校准产物；历史引用不得因新版本启用被删除到无法恢复。checkpoint较旧可以重放追赶，缺失尾部不能用最新盘口补造中间决定。

### 恢复

1. 撤销旧会话输出资格，恢复核心权威订单、经济、占用和原请求状态；策略尚不获得交易权。
2. 验证checkpoint来源、内容哈希/schema/版本/摘要及依赖资料；核对cursor与可重放日志连续范围。损坏、依赖缺失或不兼容时停止该策略激活，不把状态置空继续。
3. 从cursor之后按相同确定顺序重放规范事件、TimerEvent及ConfigEvent。输入批次边界对策略无语义；输出关闭，但确定路径仍推进IntentSequence并验证预期意图。
4. 在指定屏障核对冻结计划、模型/信号/监测摘要及经济引用；检查目标冻结次数、预算计数、机会消费和退出原因。checkpoint中的旧余额/订单缓存不能覆盖核心新事实。
5. 完成Venue订单/账户对账，处理迟到Fill、费用与Unknown；原身份查证，不能把重放产生的历史意图重新发出。核心已持久接收的未完成请求仍由既有核心恢复链承接，不由Python换身份重提。
6. 校验时间证据，停机计入原期限。周期已到期则按原安全权限退出；机会已到期则失效。跨机时钟不足以证明剩余预算时，不允许猜测为“还有完整期限”，保留风险并由核心安全流程核对/处置。
7. 应用当前HostActivated屏障取得新StrategyActivationIdentity，并满足当前权限、健康、风险及用户显式恢复新开仓要求。两者均不能由checkpoint字段替代；获准安全动作与获准新开仓分别检查。

上述步骤并不禁止核心在策略恢复期间执行已有权限范围内的查询、撤单和安全减险；不依赖损坏的策略状态才能履行存量风险管理。旧会话迟到输出、重复恢复完成通知及旧checkpoint发布不能反向覆盖当前状态。

## 6. 请求边界与崩溃切点

| 崩溃切点 | 必须保持的语义 |
|---|---|
| 信号确认前/后 | 按重放输入确定是否真的触发；不基于当前高分补发历史机会 |
| 候选重评中 | 恢复同一机会、deadline、预算和随机材料；不能多领一次评估额度 |
| 已提出预留请求但未知道结果 | 标记请求未决并按原身份查证；不得清成“未预留，可新开” |
| 核心预留成功而策略尚未观察 | 重放/核对该核心事实后消费原信号；不得为同一配对再建周期 |
| 意图提交/发送/回报边界 | 保留身份及可能成交量；无权重放不补发，Unknown不视为未发送 |
| S1目标冻结前/后 | 依据对应事实确定pending/frozen，只冻结一次；重复事实不再次缩放 |
| 退出触发后、第一笔退出发送前 | 恢复后仍须保持退出已触发，不等待重新达到止盈；有权且核对后继续原退出 |
| 完成对账/残余承接/占用释放边界 | 只有完整事实支持时才标Completed并起冷却；不能提前释放或把残余清零 |

## 7. 版本切换

同版本重启保持StrategyInstanceIdentity及意图身份空间；新Host会话身份变化只影响授权包络。Keep/Migrate/Rebuild必须显式声明，遵守CutoverDrain/CutoverBarrier，不能让旧参数与新模型混合工作。

Migrate需证明既有经济关联、冻结目标/期限、锁存和next IntentSequence不被丢失或重新解释；Rebuild只重建获准的策略计算状态，不能用它抹掉存量风险。StrategySuccessor按既有新实例规则接替，不恢复旧实例交易权限。具体迁移实现是核心/策略实现交付，不是本规格默认批准任意热切换。

| S6-K | 入场/持仓/退出期限在停机中到期，或时钟证据不可信 | 不重置期限；不可信时不授予虚构剩余预算，保留安全管理 |
| S6-L | 错schema/hash/模型版本、缺失日志尾、数值非法 | 拒绝策略激活，不能静默清状态；核心存量风险仍被管理 |

| S6-O | 非法大小/满容量、残余/历史引用待承接 | 不删除未解决证据换取资格，不提前Completed |
| S6-P | Keep/Migrate/Rebuild及StrategySuccessor切换 | 按各自身份/屏障合同处理；经济事实、原期限和锁存不重置 |

测试应从Host输入/输出与核心规范事件、checkpoint发布/恢复接缝驱动；仅测试序列化往返或直接改私有字段不足以通过。证据输出至少包含版本哈希、输入摘要、崩溃切点、恢复屏障、前后状态摘要、意图/拒绝记录及核心占用/经济结果。

## 9. S1–S6一致性与剩余交付

| 交叉项 | 已统一的规则 |
|---|---|
| S1/S2 | 参考收益生成原目标；部分成交缩放一次，保留绝对下限；实际计划收益只做准入/排序 |
| S3/S5 | 只在准入阶段检查概率；Holding单次下降不新增退出，模型失效按独立谓词处理 |
| S4/S6 | 预测/目标取整方向明确，恢复不能改目标或期限；数值与编码资格仍需实现证明 |
| S5/S6 | 同次机会deadline/次数/消费证据保持连续；模型健康不解除其他锁存 |
| H2/H3 | 预留、占用和经济事实由核心承接，策略只保存关联；未知结果不另开周期 |

六项规格均已形成文档，不等于研究校准或上线完成。剩余工作明确为：实际参数与样本外证据、H1–H3核心设计实现、策略实现/数值编码、上述公共接缝验收及另行授权运行验证。不得将本地文档检查写成这些项目已通过。
