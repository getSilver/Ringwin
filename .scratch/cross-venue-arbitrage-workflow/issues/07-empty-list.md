## Question

没有批准记录时核心如何处理开仓？

## What to build

StrategyInstance 加载即读取名单，每次新增开仓检查有效批准。

## 验收条件

- [x] 首次启动、撤销最后一项和重启均拒绝新开仓，无需开启白名单开关。
- [ ] 策略页显示“策略交易名单为空，请从跨所机会扫描器添加配对”。
- [x] 用已有敞口验证撤单和减仓仍可进行。

## 实现与证据

实例加载时向核心读取有效名单状态。启用前，核心按实例绑定的部署账户识别跨 Venue 范围并持久记录，开仓和增险改量均检查有效批准。

Windows 离线回归使用两个模拟 Venue、持久日志、合成订单回报和规范成交，验证首次空名单、撤销最后一项和重启后拒绝开仓，已有挂单可撤，成交后的敞口可用 reduce-only 订单减仓。

已接入权威连接的 Web 策略页支持空名单提示，同步更新内置页面和 RingwinUi。默认 `python/control_plane_node.py` 只接入扫描与只读资产投影，策略实例端点缺少 `instance_source` 和发布管理器。默认启动路径的页面验收仍待核心实例服务接入。
