## Question

异结算币路线如何统一比较并对账？

## What to build

修订 ADR 0022 的策略估值及配对范围，贯通扫描估值、核心批准与策略收益报告。

## 验收条件

- [x] USDT/USDC 内部按 1:1 比较，两腿不同结算币可批准；账户余额、保证金、费用与交易所对账保留原币。
- [x] 汇率为 0.998 USDT/USDC 时，净收或净付 1,000 USDC 的平价偏差分别为 −2 或 +2 USDT；扫描预估与策略实际分别展示。
- [x] 持仓按有符号数量和汇率变动归因，重复采样不重复记账；保存行情时刻和来源，缺汇率标示待补。

## 实现与验收证据

- ADR 0022 规定策略平价口径。核心定向验收使用模拟账户，混合 USDT/USDC 结算路线批准、撤销和持久恢复通过，两账户仍按原结算币记账。
- 扫描使用节点汇率文件，按场景估算净 USDC 流量，归档来源和时刻。离线回归覆盖不同报价精度、跨环境登记敞口和 USDT 费用的原币归因。
- 私有策略权威通道从 Owner 已提交的周期账务投影原币现金流。资金费归属须有 VirtualPortfolio 和周期持仓证据，归属或热历史不足时显示待补。IOC 和 Maker 的策略动作可附实际汇差。FX 归档保存核心 barrier、原币入账事实、闭合时刻及 UTC 行情引用，重开后用相同证据复算。
- 离线模拟用核心原生成交和资金费入账，重复成交只出现一次。恢复后投影输出直接进入 Python 策略报告，净收 1,000 USDC 在 0.998 下显示 −2 USDT。另有定向回归覆盖净付、正负持有量、平仓后停止持仓归因、缺行情和历史缺项。正式前端批准、双 IOC 和场所对账由 [11](11-dual-ioc.md) 验收。
