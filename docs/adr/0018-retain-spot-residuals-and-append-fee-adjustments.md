# 保留现货残余归属并追加独立费用调整

用户于本窗口明确要求实施残余承接与独立费用调整，扩展 09a 先前仅精确零释放的首版范围。沿用 ADR0017 的同一 TradingShard/Writer 权威和原子周期终结，不新建锁表或账本所有者。

- 正现货尘埃只有在显式版本化 Asset 规则、单笔/累计上限、存续时间与容量校验通过时才可承接后释放周期键。未配置规则默认拒绝；夹具参数不构成生产阈值批准。余额、估值和风险归属保留，残余从新周期可花费数量扣除；永续残仓、负资产、Unknown 和经济证据缺口仍阻止释放。后续处置使用既有核心意图和权限，不以承接授予补买、自动归集或跨所有者转移权限。
- FeeAdjustment 使用独立的来源更正身份和证据，引用原 Fill 与前一费用版本。核心追加原币调整事务，不覆盖原成交或原始账务，不改变 OMS 报告累计、唯一已应用成交量或 AverageCost。跨币种分别冲回与记入，首版只接受非负 TradingFee 更正且不改变 TradingRebate；重复幂等，冲突、缺证据、错误版本继续失败关闭。
- 迟到事实仍归原账户、组合和周期，不能被重用账户品种键的新周期接收。新经济事实须重新覆盖对账；更正通路不自动解除既有经济故障。冷归档引用必须认证原归属，不能从当前订单或余额推测。

选择保留残余及追加调整，避免通过清零、静默覆写或转入 Treasury 掩盖资产与历史；代价是维护有界残余/更正身份与恢复证据。延续 ADR0013/0014/0015 的持久提交、历史认证、快照和重放约束，旧格式失败关闭。本决定不替代具体 Venue 凭证支持、生产参数冻结或运行资格验收，也不解除 08、09b/09 的既有依赖。

现有 InstrumentRules 未完整表达 Venue 最小订单金额，首版残余资格保守限定为 gross 持仓、OpenCost 和保证金精确归零后，不足一个 lot 的正原子余额；仍有 gross lots 但低于 Venue 最小订单要求的余额继续占用。不得以策略配置中的阈值替代缺失的交易所规则证据。
