# 残余可在原所有者内复用，由人工显式冻结

用户明确改变残余政策：取消最大存续时间及其到期停开行为，残余留下可追溯记录，默认允许新周期花费；人工决定冻结和解除冻结。本决定取代 ADR0018 中的期限、永久不可花费及因正常复用引起的库存不足锁存要求；ADR0018 的独立费用更正、原归属与其他安全约束继续有效。

单笔承接仍要求 gross lots、OpenCost、保证金归零且正余额不足一 lot。累计风险额度针对当前尚未消费的残余，不把不可变历史承接数量永久累加；额度可以允许积累到处置门槛，具体 Asset 数值仍需显式配置，不从测试夹具或交易所最小额度自动推断。

原始承接记录不可变，当前剩余及冻结数量须通过可重放事实维护。使用范围限定原账户、VirtualPortfolio 和 Asset；真实成交与费用不能被拒绝以维持历史残余数量，也不能重复承接或重复计算资产。冻结不能追溯占用已消费或在途授权数量，解除冻结不清除其他经济故障、Unknown 或未闭合对账门槛，不授权自动补买、卖出或兑换。

人工控制沿用现有 Web 控制面与核心权威输入，带稳定身份、版本和权限证据；不另建控制 CLI。该决策不代表代码、界面或资格已验收；原 717/717 仅属于旧政策基线，调整后须重新验证。
