# Triage 标签

工程技能使用五个规范角色。右列是本仓库 GitHub Issues 中实际使用的标签字符串。

| 规范角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理独立执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或操作 |
| `wontfix` | `wontfix` | 已决定不处理 |

技能提到规范角色时，使用表中对应的 GitHub 标签。若仓库以后调整标签，只修改右列，避免在各技能
中重复配置。
