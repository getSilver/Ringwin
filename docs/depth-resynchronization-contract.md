# 增量深度及重同步合同

任务：[03 增量盘口失效与重同步闭环](../.scratch/cross-venue-core-interface/issues/03-depth-resynchronization.md)。延续 [双边深度合同](depth-snapshot-contract.md)，不赋予新的执行权限。

## 所有权与连续更新

OKX MarketFeedAdapter 从捕获的 RawIngress 解码更新，在自身有界 BookDepth 上按价格应用全部档位：正数量替换或有序插入，零数量删除，删除不存在的价格不改变结果。同一帧重复价格拒绝；双侧候选全部校验后才发布，不暴露中间状态。价格、数量必须精确转换到当前规则 ticks/lots，非正价格、负量、交叉、空侧及数值溢出失效。

规范 L2BookDelta 新增可选 `depth`，是适配器在声明的 `previous_sequence` 上应用本次更新后的完整有界 postimage，不是交易所全量快照。它保留源序列、前驱、规则、接收可见时间、全部档位和覆盖证据。Projection 仅在已有健康快照且前驱匹配时应用，检查 scope、活动规则及深度结构。该 postimage 不得独自恢复 gap。兼容的旧顶部增量 `depth=null` 会撤去多档资格。

同序列规范增量仅在与最后接受的完整增量相等时幂等；数量、尾档、前驱、覆盖、时间或规则变化均冲突。最后增量进入快照与 CanonicalStateDigest，因此重启不改变重复判定。OKX 私有 decoder 按原始内容去重，允许非单位递增序列及无变化心跳；倒退、前驱缺口、冲突重复均产生有捕获证据的 gap。规范接缝保留其他 Venue 按显式前驱声明的序列重置语义，不以 `sequence == previous + 1` 代替前驱证据。

## 容量与缺失信息

每侧最多 8 档。快照超过容量仍校验收到的全部尾部，保留前 8 档并声明截断；消费不能超出覆盖。为避免从未知尾部补档，截断快照后的任何增量均失效并要求新快照。非截断候选增量新增比当前最深档更差的价格时，因不能证明中间未知尾部为空而失效；不凭单个更新扩大已知覆盖。插入第 9 档也失效，不静默丢弃后宣称连续。这个首版合同牺牲可用性；不声称支持 OKX 400 档持续 book。

规范深层 `lots=null` 仍表示未知，quote 消费到该档返回不足；不填零或外推。OKX 更新缺少数量、非法 decimal、超出有界输入和畸形帧关闭深度资格。可定位的畸形 book 使该品种 gap；不能定位的拒绝输入保守使已观察规则的订阅品种 gap。超过 1 MiB 的原始帧仍先交 RawSink 保存原字节证据，再以拒绝记录关闭资格，不进入 JSON 解析；回放执行相同拒绝。RawSink 不可用/背压及超过 u32 原始长度等无法提交证据的硬错误必须由接入 owner 停止运行，不能继续宣称已提交新的行情事实。无效 canonical 顶部数量、主品种旧 i64 范围或可见时间也先撤销旧资格，失效通过既有稳定拒绝路径保存。

## 重同步与并发输入

缺口、乱序或转换失败后增量不能恢复资格。快照只能使用大于最后可见序列的新完整结果；迟到或冲突快照使资格失效且不替换旧内容。重复一致的私有快照可被去重，但不能作为 gap 后恢复依据。规则激活清空旧 book 和最后增量，必须接收对应规则的新快照。

采用串行捕获顺序，不缓冲乱序增量：快照前的增量不回填；快照后的第一增量必须衔接该快照或其后最后接受序列，否则再次 gap。有效较新快照替代不可信 book，不声称补全丢失的历史，也不重新触发过去的策略决定。订阅重建由现有 beginSubscription 提供捕获的 reset 证据；核心仍要求新快照。该票实现资格闭环，不新增网络重连管理器。
